# Templates 目录索引

高中思想政治15分钟师范生技能大赛输出模板 V1.0。依据用户指定的字段与既有方法、工作流、评分框架建立。状态：V1.0已建立，待实际使用校准。

| 模板 | 用途与适用范围 | 主要承接依据 |
| --- | --- | --- |
| [15min-lesson-plan-template.md](15min-lesson-plan-template.md) | 完整设计后的正式教学方案、最终比赛版本及磨课成果整合 | [从零设计](../../references/workflows/design-from-scratch.md)、[磨课](../../references/workflows/polish-existing-lesson.md) |

| [judge-scorecard-template.md](judge-scorecard-template.md) | 完整模拟评委报告、评分与同口径前后比较 | [模拟评委](../../references/workflows/mock-judge-mode.md)、[100分标准](../../references/rubrics/competition-rubric-100.md) |

模板负责稳定输出，不负责替代教学思考。先依据workflow与相关reference完成设计或评价，再组织输出；不得跳过诊断直接填表。

填写时替换方括号提示，关键缺项标为待核验；按任务完整使用、适当简化或只取相关部分，删除无价值重复。核心逻辑与评分证据不能因裁剪丢失。版本、修改日期、本轮重点修改按真实输出填写，不能将预设或建议写成已实施。

模板中的可重复节点不限定六问，回答分支和3项优缺点不强制凑齐。快速评课不展开完整评分报告，问题链专项不自动扩成整份教案。模板没有预置教学结论、得分或完整课例。
