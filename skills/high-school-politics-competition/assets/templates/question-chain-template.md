# 问题链专项设计

> 模板资源：高中思想政治比赛课问题链专项设计模板 V1.0。
> 用于问题链设计、优化、认知推进分析、可能回答及教师追问的专项输出，不自动扩成完整教案。先按任务读取 [核心认知冲突](../../references/methods/core-learning-conflict.md)、[六步问题链](../../references/methods/six-step-question-chain.md)、[学生认知活动](../../references/methods/student-cognitive-activities.md) 与 [教师追问](../../references/methods/teacher-follow-up-questions.md) 中的相关规则。
>
> 模板负责组织结果，不替代教学判断。方括号是提示，成品替换为具体证据或注明待核验；可合并重复内容，只展开用户所需部分。六步是认知功能，不是固定六问；主问题通常3—5个，可按片段调整。回答分支是可能路径，不要求每问实际出现全部类型。

## 十、问题链自检

[逐项按实际内容核验，未完成或无证据时标明。]

- [ ] 是否围绕同一个核心教学问题？
- [ ] 前一问是否为后一问提供认识基础？
- [ ] 是否至少有一次可信的认知冲突或解释不足？
- [ ] 是否排查并列问题和认知断点？
- [ ] 是否避免所有答案都能从材料中直接抄出？
- [ ] 是否要求学生解释、判断、比较或辨析？
- [ ] 是否有依据回答继续追问的空间？
- [ ] 学生是否有修正或深化认识的路径？
- [ ] 理论是否有分析基础并得到必要规范？
- [ ] 是否通过迁移检验新认识？
- [ ] 是否删去重复、碎片化或低价值问题？
- [ ] 是否适合约15分钟，计入思考、回答与追问时间？
