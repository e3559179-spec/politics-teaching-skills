## 一、问题串与问题链

问题链不是“多设计几个问题”，其本质是认知推进结构，不是问题数量。

**问题串**：几个问题依次出现，但彼此没有真正的认知依赖关系。例如“材料说了什么—为什么会这样—有什么启示”，可能围绕同一主题，却仍能各自独立回答。不能仅凭这些问句形式判定好坏，要检查学生上一问形成的认识是否被下一问使用。

**问题链**：前一个问题为后一个问题提供认知基础，学生回答中的判断、理由或困难推动课堂进入下一阶段；原有理解被检验、修正或深化，最终形成学科概念、原理或有依据的价值判断，并在新情境中使用。

用功能关系检查：Q1提供初步判断，Q2分析其理由并暴露解释边界，Q3使边界成为需要解决的冲突，Q4比较并修正解释，Q5抽象出学科认识，Q6检验其迁移。这是逻辑示意，不要求实际编号正好为Q1—Q6。

对任意相邻主问题写出一句“因为学生在上一问已经形成或暴露了……，所以下一问要……”。如果只能写“接下来学习另一个知识点”，通常尚未形成认知依赖。删除或调换关键问题后，若后续推理完全不受影响，应重新检查必要性；不是要求每个辅助小问都不可删除。

## 二、六步不是并列关系，而是认知递进关系

本 Skill 采用“初判—析因—冲突—辨析—建构—迁移”作为核心认知模型：

```text
初判：我怎么看？
  ↓ 提供初步判断
析因：为什么我这样看？
  ↓ 形成可检验的理由与解释
冲突：原来的解释够不够？
  ↓ 暴露不足、矛盾或适用边界
辨析：哪种解释更合理？依据是什么？
  ↓ 形成有理由的修正
建构：我们可以形成什么学科认识？
  ↓ 得到可使用的概念、原理或判断
迁移：这个认识能不能解释新的问题？
```

六步描述学生认识如何变化，不是六个固定环节或必须出现的六个主问题。可以采用4个主问题加追问、5个主问题，或3个核心问题加多层追问；只要六个认知功能能够在节点及其回应处理中找到依据即可。一个主问题可以承担相邻的多个功能；辨析中也可因新回答返回析因或重新检验冲突。

不要求学生每次都先答错。准确的初判也可以经历理由补充、条件检验和认识深化；不能为凑模型安排虚假错误或强迫分歧。若片段缺少自然的解释边界，应调整核心问题、材料或片段取舍，而不是演出“学生突然不懂”。

**功能缺失的风险**如下；合并实现不算缺失：

- 没有初判：缺少可辨认的学生起点，后面的“认识变化”无从比较。
- 没有析因：只有观点表态，难以判断哪些理由需要检验。
- 没有冲突：原解释无需接受挑战，课堂容易退化为教师引导学生验证已给结论。
- 没有辨析：冲突虽出现，却由教师直接消除，学生没有处理依据与修正观点。
- 没有建构：讨论停留在这个案例，未形成明确的学科认识。
- 没有迁移：缺少在新条件下使用认识的证据，不能仅凭复述断言学生已经掌握分析方法；这不等于前面所有学习都无效。

## 三、六步认知功能的设计规则

### 1. 初判：呈现真实认识起点

**功能**：让学生基于经验、直觉、前概念或已有知识作出判断，显示已经知道什么、倾向如何理解、可能有哪些不同看法，以及后续教学的入口。不要先公布新概念再要求学生重复。

**如何生成**：

1. 给出学生看得懂、完成初判所必需的简洁信息，保留判断空间。
2. 设计一个可选择、可判断或可表达初步立场的问题，同时要求简短理由；不把背出新理论设为入场条件。
3. 预判有依据的不同回答及不完整回答，标为假设；实际呈现时依据学生回答修订判断，不能冒充调查结果。

**问题方向**：“如果你是其中一方，你更支持哪一种方案？为什么？”可暴露经验和理由；“价值判断和价值选择具有什么特点？”通常需要已掌握新知识，不宜直接承担初判功能。前者也须有具体可比较的信息，不能只凭身份标签让学生猜立场。

**如何判断完成**：能记录学生初步判断及至少一个理由线索，或在设计中明确预设判断与依据。允许不同答案，不强求现场必然出现分歧。其输出将成为析因要解释的对象，并为后续冲突提供可检验的起点。

**避免**：答案已写在PPT上；材料复杂到学生无法进入；只问“同意吗”不留下理由；教师暗示唯一正确立场后再让学生选择。

### 2. 析因：从“我怎么看”到“为什么这样看”

**功能**：解释初判，不重复现象。学生通过比较、归因、条件分析、寻找影响因素、区分立场与解释观点差异，逐渐从生活经验进入学科分析。

**如何生成**：

1. 从初判提取两种判断，或同一判断的不同理由，不临时换成无关的新问题。
2. 要求比较哪些信息、主体条件或判断依据不同，说明这些差异如何影响结论。
3. 对“每个人想法不一样”等循环解释继续要求原因，将笼统表达转为可被后续检验的解释。

**问题方向**：“为什么面对同一个问题，不同主体会作出不同判断？”学生需指出差异与判断之间的联系，不只是列出主体名称。分析立场是解释其观点的形成，不等于承认每种判断都同样合理。

**如何判断完成**：学生从表态推进到“因为存在某条件或依据，所以作出某判断”；能指出解释覆盖了什么，尚未回答什么。冲突阶段应针对这个解释的不足，而不是另起一个难题。

**避免**：反复问“还有什么原因”收集清单；把材料原句换个顺序当作解释；将主体或利益视为不需论证的唯一决定因素。

### 3. 冲突：让原有解释接受检验

**功能**：使学生意识到原解释存在不足、矛盾、边界或无法解释的新情况，是由经验判断进入理论建构的重要转折。按本框架，高质量比赛课原则上至少有一次明显认知冲突；“明显”指能指出哪个原解释遇到了什么困难，不指场面激烈。

**如何生成**：

1. 写出需要检验的原判断、理由及其隐含前提。
2. 选择新材料、反例、追问、立场变化或时空变化，只改变与该前提相关的关键条件。
3. 要求学生先用原解释处理新情况，表达哪里解释不了、是否出现矛盾、需要增加什么条件。
4. 将困难保留下来交给辨析处理，不立即宣布正确理论。若学生原解释已能成立，就检验其边界并深化理由，不假称其失败。

**可用的冲突来源**：反例、不同主体、利益差异、概念边界、事实与直觉不一致、时空条件变化，或两个都看似合理却存在张力的观点。选择有内容依据且学生能处理的一种即可，不叠加多重悬念。

**假冲突**：教师说“其实没有这么简单”，随后自己解释；材料虽然出人意料，但未挑战学生的任何解释；学生只是看到了新闻反转，没有认识困难。

**真冲突**：能记录“原先认为A，因为B；新条件C使B不足以支持A，需要重新判断”。例如，学生已解释不同主体为何产生不同判断，教师继续问：“既然不同主体都有自己的判断，那是不是意味着所有价值判断都同样正确？”这只是把描述差异与评价合理性之间的缺口显现出来，并未预先证明任何具体结论。须继续要求理由与判断依据，才能进入辨析。

**如何判断完成**：学生或可检查的预设回应能指出原解释不够用在哪里，而非只说“很复杂”；后续任务明确要处理这一缺口。设计预评只能说明可能引发冲突，不能声称真实学生已经经历认识转折。

**避免**：用冷僻知识难倒学生；偷换概念制造矛盾；故意隐瞒判断所需事实；把主体意见不同直接当作已经发生认知冲突；为反转而否定合理回答。

### 4. 辨析：处理冲突并修正解释

**功能**：通过比较、质疑、反驳、论证、条件分析、正误判断和观点修正，弄清为什么一种解释不充分，另一种解释更合理，以及结论成立的条件。不是猜教师想要哪一个答案。

**如何生成**：

1. 把冲突改写为学生需要判断的焦点，如“分歧在结论、依据还是适用条件”。
2. 指定比较或论证对象及可用证据，要求学生说明理由；无需在15分钟同时开展全部思维活动。
3. 预留澄清概念边界、判断依据、隐含前提与逻辑漏洞的追问方向。支架帮助学生继续判断，不直接代替判断。
4. 根据回答组织观点比较，要求保留、修正或放弃原解释的哪一部分，并说明原因。

**如何判断完成**：能找到“原观点—检验依据—修正内容”的联系；学生不仅选择答案，还说明何以成立。教师处理的是真正分歧，而不是泛泛说“都有道理”或直接宣布哪组获胜。

**接向建构**：提取辨析中已经成立、可概括的关系或条件。如果学生仍未处理关键漏洞，应继续支架或收窄问题，不能强行进入理论宣告。

**避免**：标准答案提前可见；教师把全部论据说完再让学生齐答；将反驳理解为攻击发言者；只强调形式上热烈而不比较依据。

### 5. 建构：从辨析结果形成学科认识

**功能**：把前面形成的经验、比较和辨析结果，上升为高中思想政治学科概念、原理、规律或有依据的价值判断，说明它们之间的逻辑联系。理论不能突然由教师“端出来”。

**如何生成**：

1. 确定哪个问题的回答已经形成可抽象的认识、可以对应哪个学科概念或关系。
2. 让学生先用自己的话表达，教师提取并板书关键词，再追问共同点、关系或条件。
3. 引导学生概括，教师进行必要的规范化、概念澄清和理论补充，指出该结论来自前面哪一步分析。
4. 依据所用教材与课标核验正式表述及边界；未提供或未能核验时标为待核实，不编造原文。

可采用“学生表达 → 教师板书关键词 → 教师追问 → 学生概括 → 教师必要规范化 → 形成学科结论”的路径，不机械要求每次逐项表演。

**教师职责**：抽象、概括、规范表达、澄清概念、补充必要理论、建立知识之间的逻辑联系。“学生主体”不等于教师不能讲。教师应在学生已有认知基础后作简洁、准确、有理论高度的提升；不能以少讲为由放任错误，也不能以完整为由包办推理。

**如何判断完成**：结论准确且有前面分析的支撑，学生能说明至少一处判断依据或适用条件。若需要补充无法由该案例推出的理论，说明是必要理论补充，不伪装成学生自行发现或由一个案例证明的普遍规律。

**接向迁移**：明确要让学生在新条件下使用的分析关系或判断依据，避免只留下一个待背诵的概念名称。

### 6. 迁移：在新条件下检验认识

**功能**：检查新认识能否用于新材料、新案例、新主体、新场景或新问题，支持从“理解这个案例”到“会用一种分析方法”的判断。只问“今天学到了什么”属于回顾，不能单独证明迁移。

**如何生成**：

1. 保持核心学科关系不变，改变一个有意义的条件，避免只换人名。
2. 给出短小且信息充足的新情境，让学生运用刚形成的认识作判断、解释、现实分析或观点评价，并说明依据。
3. 预设可观察的成功表现及常见误用；教师依据回应检查学生是否考虑了变化的条件，必要时做简短纠偏。

**如何判断完成**：学生能调用前面形成的理论，说明新旧条件的联系或差异，而不是套用原答案。无生试讲只展示可实施的检测任务与处理路径，不宣称学生已掌握；一次迁移也不足以证明长期、普遍掌握。

**15分钟尺度**：短、小、准，一次简洁迁移即可；不另开新课题，不引入必须重新讲授的一组概念，不以课后“思考一下”代替本片段中的迁移设计。

**避免**：重复原题；只有选择而无依据；更换情境后实际考另一知识点；迁移题太长，最终只能由教师公布答案。

## 四、AI问题链生成流程

### 生成前：核对任务与依据

提取课题、教材与课标依据、学生起点、比赛形式与时限、已有核心问题及材料。先理解整课与知识结构，再选择片段；不把45分钟内容机械压缩。

只追问会影响当前设计的关键缺项。将学情、学生回答和时间估计明确标为预设；材料中的事实与教材原文需有来源，缺少依据时标注待核验。若用户已有确认框架，保留它并只完成当前所需问题链，不擅自重写整课。

### Step 1：确定核心教学问题

先回答：这一知识点真正解释什么问题？学生容易在哪一步误解？哪两个认识之间有张力？本片段最值得解决什么认知问题？

**输出**：一个可明确作答、适合本片段的核心教学问题，附“学生原有认识—希望形成的新认识”的差异及片段取舍理由。教材标题可提供范围，不能直接把标题改成疑问句就视为完成。

**检查**：回答它是否需要学生解释、判断或辨析？能否在约15分钟聚焦解决？若必须另讲多个主题才能处理，先收窄范围。

### Step 2：写出学生初始判断

预测未学习新知识前可能出现的判断、理由和不完整解释，并注明依据。允许学生已有部分正确认识，不为制造冲突故意低估学生。

**输出**：初判问题、可能回答及差异；接续析因问题，说明如何把“怎么看”转为“为什么这样看”。至少提供可比较的回答可能性，但不要求实际学生必然出现所有预设分支。

**检查**：学生能否凭已有知识进入？析因是否解释初判，而非重复材料？这里必须落实析因功能，不能因生成流程名称不同而遗漏六步中的第二步。

### Step 3：寻找原有理解的边界

针对上一步理由问：“在什么情况下，这个解释会失效、不充分，或者需要限定条件？”

**输出**：待检验的原解释、隐含前提和边界。区分“描述了不同判断为何形成”与“判断何者合理”等不同层次，避免把不同问题混为一谈。

**检查**：边界是否与核心学科认识有关？若原解释在现有条件下已成立，寻找需要补充说明的条件，而不是强行判错。

### Step 4：制造认知冲突

从反例、主体变化、时空变化、利益差异、概念边界、事实与直觉不一致、两个看似合理的观点中，选一种能够检验该边界的方式。

**输出**：必要新信息、冲突问题、原解释为何不足，以及学生可能如何察觉困难。这里的“制造”指设计检验条件，不指伪造事实或学生反应。

**检查**：要求学生使用原解释后，是否会遇到可说明的困难？如果只有教师一句“没有那么简单”，回到Step 3修改。

### Step 5：安排辨析任务

围绕冲突安排判断、比较、论证、质疑或修正，明确比较对象、可用证据和理由要求。

**输出**：辨析主问题、学生主要认知操作、可能的错误或不完整回答、教师追问方向，以及修正后应保留或改变的认识。

**检查**：学生是否承担关键推理？教师支架是否只是帮助继续分析？如果所有论据和答案都提前给出，应减少代答、重设任务。

### Step 6：设计理论生成点

确定哪个回答之后，学生已具备抽象某个学科概念、原理或判断的基础。

**输出**：生成点所在节点、学生已有表达、可板书的关键词、概括问题、教师必要规范化内容及其依据。区分学生已形成的认识与教师需要补充的理论。

**检查**：能否追溯结论来自哪一次比较或辨析？若只有“教师总结”四字而没有认识基础，返回Step 5，不把标准理论硬接到活动末尾。

### Step 7：设计迁移任务

用一个简洁新情境改变关键条件，让学生调用所建构的认识并解释。

**输出**：迁移问题、新旧条件的差异、预期判断依据、常见误用及简短处理方向。

**检查**：是否仍围绕同一核心学科认识？是否要求运用而非复述？如果需要另教新知识，缩小迁移任务。

### 生成后：组合节点并校验

把七个生成步骤的产物组合为3—5个核心主问题及必要追问，不将七个生成步骤直接变为七个课堂问题。为每个节点标出所承担的六步认知功能、预计用时和前后依赖，检查六个功能均有承载位置；再按末尾自检表修正。

**默认交付**：核心教学问题与依据、认识变化主线、标准问题节点、六步功能映射及用时合计、待验证项。只输出当前问题链所需内容，不自动扩展完整教案、课件或案例库。若同时要求评分，读取 [比赛课100分评价标准](../rubrics/competition-rubric-100.md)。

## 五、标准问题节点格式

每个主问题使用以下字段；可承担多个相邻认知阶段，但要说明各阶段怎样发生。不是每个小追问都建立一个新主节点。

```markdown
### 问题节点：编号与简短名称

- 认知阶段：所属功能；如合并，说明功能间如何推进。
- 主问题：实际面向学生的问句。
- 为什么在这里问：本问目的，以及接续上一问的哪一项认识。
- 学生主要认知任务：操作＋对象，如“比较两种理由的适用条件”。
- 学生可能回答：合理的不同回答及依据；标明为预设。
- 错误或不完整回答：可能的误解、跳步或缺失条件，不刻意编造错误。
- 教师追问方向：针对上述回答分别如何澄清、要求依据或继续分析。
- 希望形成的认知变化：从什么认识到什么认识，如何观察。
- 对应的知识生成：本问形成的新关系、阶段性认识或学科结论。
- 与下一问题的逻辑关系：本问留下何种基础或未解困难，下一问为何必要。
- 材料与依据：所需信息、来源或待核验状态。
- 预计用时与实施证据：计入阅读、思考、回应、追问与板书；
  标明是设计估计、模拟呈现还是实际记录。
```

中间节点不必强行产生一个教材知识点；“知识生成”可以是待检验的阶段性认识。最终迁移节点的“下一问题逻辑”写明本链收束及根据迁移回应如何反馈，不为填字段另开新课题。

### 单节点示意：析因

以下仅示范节点记录，不构成完整教案。城市更新场景和学生回答均为教学预设，不代表现实主体一定持有某种观点，也不是教材原文引证。

- **认知阶段**：析因。
- **主问题**：为什么面对同一个城市更新方案，不同主体会作出不同判断？
- **为什么在这里问**：承接初判中的方案选择，分析判断差异来自什么条件，而非停留在立场表态。
- **学生主要认知任务**：比较不同理由，归因并分析条件。
- **学生可能回答**：居民可能强调生活质量，开发商可能强调经济收益，文保人士可能强调历史文化；同一主体也可能同时考虑多种因素。
- **错误或不完整回答**：“因为每个人想法不一样”；把主体身份当作唯一原因，或把判断差异直接当作合理性证明。
- **教师追问方向**：“为什么想法不同？只是性格不同吗？”“材料中的什么信息支持你的归因？”“同一类主体一定作出相同判断吗？”
- **希望形成的认知变化**：从笼统的个人差异，推进到分析主体立场、利益、需要等条件，并不据此认定所有判断都合理。
- **对应的知识生成**：形成关于价值判断和价值选择主体差异性的阶段性认识；正式概念表述应核对所用教材。
- **与下一问题的逻辑关系**：已经能解释判断为什么不同，但尚未回答不同判断是否都合理，需要进一步检验。
- **材料与依据**：需提供可支持不同理由的方案信息；实际使用时补充或核验来源，不能只给身份标签让学生猜测。
- **预计用时与实施证据**：结合阅读量与前后节点填写设计估计并试讲核验；此节点示意不虚构实测时间或学生表现。

## 六、诊断与修改已有问题链

1. **还原证据**：提取实际主问题、必要追问、学生回答及教师如何处理，注明问题编号或真实时间位置。只有教案时评价设计预期，不冒充课堂效果。
2. **映射功能**：把每个节点标到六步认知功能，允许一问多功能；找出功能缺失、重复或顺序跳步，不能以缺少某个标题判断失效。
3. **检查连接**：逐对写明“前问产出—后问依赖”；做关键节点删除或调序检查。重点查找从生活回答直接跳到理论、从冲突直接跳到公布答案的位置。
4. **追踪认识变化**：指出起始判断、解释边界、冲突证据、辨析结果和理论依据；核对学生回答是否影响追问、支架或概括。
5. **定位失败类型并局部修复**：按第十二节说明具体问题，优先修复切断认知推进的连接。保留用户已确认的核心框架，不因局部薄弱自动重写整课；如核心问题本身不适合，说明依据并提出调整方向。
6. **重新核验**：检查改动后六步功能、3—5个主问题的取舍、总时长与迁移。无实测材料时标“待试讲验证”；评分同时遵循第十三节与正式评价文件。

**诊断输出**：证据位置、失效功能或连接、为什么影响认识、最小修改方向、下一次试讲应观察的变化。资料缺失与课堂功能缺失分开记录，不给没有依据的确定诊断。

## 七、教师追问与问题链的关系

高质量问题链不能只预设主问题。每个核心问题应保留针对回答的追问空间，用于澄清、深化、要求依据、暴露矛盾、引入反例、比较观点、推动抽象或促进迁移。

“第一问体现设计水平，第二问和第三问更能体现教师专业水平。”这是提醒关注回答后的专业判断，不是要求每问固定追加两次追问，也不是以追问次数衡量水平。回答已充分时可以概括后推进，不为凑次数追问。

追问方向须与可能回答对应，并说明会怎样影响下一步；不能只列通用问句。详细方法见 [教师追问设计规则 V1.0](teacher-follow-up-questions.md)，本文件只规定接口，不重复展开追问方法。

## 八、学生认知活动与问题链的关系

每个问题都必须对应学生主要认知活动。阅读、观看、讨论、回答是活动形式，单独写这些不足以说明思考任务。

应写成提取、比较、分类、归因、判断、质疑、辨析、论证、概括、抽象或迁移，并带上操作对象或判断依据。例如“比较两种方案的判断依据”，比“讨论方案”更可检查；学生可以通过口头、书面或其他符合规则的方式表现思考，不以发言数量代替认知证据。

如果无法说明学生究竟在进行什么认知操作，应重新设计。详细分类与活动设计规则见 [学生认知活动设计规则 V1.0](student-cognitive-activities.md)，本文件不重复展开分类体系。

## 九、15分钟问题数量与时间控制

问题不是越多越好。默认推荐：

- 3—5个核心主问题，配合必要追问；
- 一个主情境与一个核心教学矛盾；
- 至少一次明显认知冲突；
- 一次有依据的理论建构；
- 一次简洁迁移。

这是帮助聚焦的内部设计建议，不是官方数量规定。冲突可在主情境中改变条件，迁移可使用同一背景下的新主体或一则很短的新材料；“一个主情境”不意味着禁止新的迁移条件。

避免10个以上彼此碎片化的提问，尤其避免为填满流程把一个认知任务切成大量“是不是”“对不对”。必要的澄清追问不机械计为新增主问题；超过推荐数量时，先检查是否确有认知必要，而不是按数量自动扣分。

**低价值小问题**：“大家看到了什么”“材料告诉我们什么”“是不是”“对不对”，若只要求复述或齐答，不能代替核心推进。它们偶尔可承担必要的信息确认；不能仅看句式就判无价值。

**高价值问题**：要求解释、比较、判断、辨析、论证或概括，并让所形成的认识成为后续基础。把“为什么”加在每个问句后面，不自动提高价值。

**时间校验**：

1. 逐节点计入材料阅读、独立思考、回应、必要追问与板书时间，合并节点内的时间只计一次。
2. 再计入未被节点覆盖的导入与转场，汇总到具体比赛时限；不得只计算教师念稿时长。
3. 超时时优先删去重复确认、装饰材料与并列活动，合并能承担相邻功能的节点，不先删掉辨析或迁移来保持表面完整。
4. 模拟或无生试讲按章程核验呈现方式，但不能以瞬间宣布讨论完成掩盖不可实施的安排。未试讲只能标设计估计。

不为六步统一规定分钟配额；时间服务于本片段最需要突破的认识困难。

## 十、问题难度梯度

推荐形成“低门槛进入 → 中等分析 → 高阶冲突与辨析 → 理论建构 → 应用迁移”的梯度：

- **前段**可进入、可表达：使用已有经验作判断，信息量足够且可读，不要求先背新概念。
- **中段**增加分析要求：从表态走向理由、条件和差异，不突然切换到学生未具备前置知识的问题。
- **核心段**出现最高思维难度：原解释遭遇边界，需要比较依据和修正认识；教师在关键卡点提供支架，而非提高材料晦涩度。
- **后段**概括后再应用：用刚建构的认识处理变化条件；迁移有新意但范围更小，不制造又一轮大规模困难。

难度不只取决于问句长短，还取决于信息量、前置知识、推理步数和支架。若起点已经较高，可减少简单确认、保留条件检验；若学生尚未理解关键事实，先提供必要信息，不把信息缺失误作高阶思考。

## 十一、问题链中的假互动识别

核查以下信号：

- 教师问完立刻自己回答，未给可实施的思考机会。
- 所有学生回答都完全符合预设，且没有展示不同回答的处理可能。
- 学生只需齐声说“是”或“不是”，无须说明依据。
- 问题答案完全在PPT上，任务等同照读。
- 所有问题都是教材原句复述，没有解释或运用。
- 教师无论学生回答什么都进入下一页PPT。
- 小组讨论没有产生或处理观点差异、理由补充或解释修正。
- 教师不处理学生答案，只作空泛表扬。
- 学生回答不影响后续追问、支架、比较对象或概括。

这些是核查信号，不是仅凭单一表象即可定罪的清单。学生全答对不必然是假互动；小组没有不同结论，也可能在比较理由、补充条件。要核验教师是否使用了回答中的信息，学生是否承担了认知任务。认知冲突也可以发生在同一观点与新条件之间，不必表现为学生相互争论。

真正的互动要求：“学生回答对课堂推进有功能。”如果学生回答可以完全删除，而追问、支架、概括内容及推理依据均不改变，则该互动大概率只是形式性互动；不要求每次回答都改变整节课的主问题顺序。

无生试讲中教师呈现预设回答不自动视为自问自答；核查任务、等待安排和不同回答的处理路径，并标明为模拟证据。真实学生缺席本身不是失分理由，预设成功也不是实际学习效果。

## 十二、问题链失败类型

### 1. 知识点问答型

- **表现**：逐条询问教材概念、特点和意义，学生逐条背诵。
- **问题**：以知识清单代替认识困难，前后回答不构成推理基础。
- **修改方向**：先明确核心问题，让概念成为解决解释困难所需的认识，而非待猜的词语。

### 2. 材料复述型

- **表现**：所有答案都是材料摘录或换句话复述。
- **问题**：只能证明定位信息，不能证明解释、判断或理论理解。
- **修改方向**：保留必要提取题，在关键节点增加基于信息比较条件、解释理由或检验结论的任务。

### 3. 问题并列型

- **表现**：多个问题同属一个主题，调换顺序却不影响思考。
- **问题**：主题相关不等于认知依赖，课堂在知识点之间跳转。
- **修改方向**：写明每问的认识产出与下一问依赖，删除不能服务主线的分支。

### 4. 教师答案诱导型

- **表现**：问句包含目标词或不断缩小提示，学生只猜教师要的答案。
- **问题**：正确回应不能证明学生理解理由，追问成为代答。
- **修改方向**：要求依据和条件，保留可成立的不同表达；减少直接泄露结论的提示。

### 5. 低阶问题过密型

- **表现**：连续大量齐答、确认和碎片化小问。
- **问题**：消耗15分钟，却未把时间留给完整解释和观点修正。
- **修改方向**：合并为少量承担明确任务的主问题，保留必要追问与思考时间。

### 6. 冲突缺失型

- **表现**：原解释始终顺利，教师宣布“复杂”后自行转入理论。
- **问题**：学生没有检验原认识，理论只作为外加答案出现。
- **修改方向**：寻找原解释的前提或边界，用恰当条件变化形成需要处理的缺口。

### 7. 活动替代思考型

- **表现**：阅读、观看、讨论环节很多，却说不出学生进行了什么认知操作。
- **问题**：形式参与无法证明认识推进。
- **修改方向**：把活动写成“操作＋对象＋理由要求”，根据认知任务选形式，而非先凑活动。

### 8. 理论突然生成型

- **表现**：讨论后教师直接展示规范结论，找不到前面的分析依据。
- **问题**：经验没有被抽象，学生可能只记住教师宣布的语句。
- **修改方向**：定位已有学生表达，补上比较、概括及教师必要规范化；区分理论补充与已推得的结论。

### 9. 迁移形式化

- **表现**：重复原题、只换人名，或只问“有什么收获”。
- **问题**：未检验认识能否用于新条件。
- **修改方向**：改变一个实质条件，要求运用同一学科认识并说明依据，控制材料长度。

### 10. 情境与问题脱节

- **表现**：热点或故事很醒目，但后面直接询问教材知识，移除情境不影响作答。
- **问题**：情境只是装饰，没有为判断、冲突或辨析提供依据。
- **修改方向**：让情境中的信息与条件成为问题推理所必需的部分；删去不参与分析的素材。

## 十三、问题链20分辅助评分建议

### 1. 与正式评价标准的关系

本节采用用户建议的4＋4＋4＋3＋2＋2＋1拆分，只用于问题链内部诊断。**不改变 [competition-rubric-100.md](../rubrics/competition-rubric-100.md) 第5项20分权重，也不替代其整体分档、其他一级指标或硬性质量限制。**

正式评分时同时读取该评价文件，先按其证据模式和整体锚点评定第5项；如需定位薄弱处，再列本节辅助分。必须分别标为“正式第5项评分”和“问题链辅助诊断分”，不得把二者相加或默认取辅助合计作为正式得分。

例如迁移得0分、其余辅助项满分时，辅助合计仍可达19分；但缺少迁移不满足正式优秀锚点，不能据19分直接判优秀。正式分与辅助分不一致时说明具体缺口，不反向修改正式锚点。

| 辅助维度 | 满分 |
| --- | ---: |
| 核心问题与主线清晰 | 4 |
| 逻辑递进 | 4 |
| 认知冲突质量 | 4 |
| 学生思维深度 | 3 |
| 教师追问空间 | 2 |
| 理论建构自然度 | 2 |
| 迁移有效性 | 1 |
| **合计** | **20** |

### 2. 辅助分的证据锚点

采用0.5分步长。以下满分条件须同时成立；部分分按缺口程度定位：仅有局部衔接或表达不足靠近区间上限，关键功能未完成靠近下限，每次写明证据。0分仅表示已确认功能不存在或无效；材料不足标待评，不记0分、不折算满分。

- **核心问题与主线清晰，4分**：4分为核心问题具体、指向明确认识困难，所有主问题均服务于解决它；2—3.5分为问题可辨认，但范围偏宽或部分节点偏离；0.5—1.5分为仅有主题名称，难以说明共同要解决的困难；0分为无共同主线。
- **逻辑递进，4分**：4分为关键连接均可说明前问产出、后问依赖，认识逐步发展；2—3.5分为部分关键连接成立，仍有并列或跳步；0.5—1.5分为主要靠串场词连接，回答很少被后问使用；0分为无认知依赖。
- **认知冲突质量，4分**：4分为原解释、变化条件和具体解释困难均可定位，困难成为后续辨析的原因；2—3.5分为存在相关冲突，但边界或学生察觉过程不充分；0.5—1.5分为只有材料反转或教师宣称复杂，尚未形成可处理的认知困难；0分为未设计或未呈现任何相关冲突。
- **学生思维深度，3分**：3分为关键任务需要学生以理由比较、辨析或论证，且能追踪观点修正或认识深化；1.5—2.5分为有解释判断任务，但核心推理部分被提示代替；0.5—1分为主要复述，只有孤立理由表达；0分为无需进行相关认知操作。
- **教师追问空间，2分**：2分为关键节点有针对不同回答的追问或处理路径，并说明如何推动认识；1—1.5分为有针对性方向，但分支或推进功能不充分；0.5分为仅列通用“为什么、还有吗”；0分为没有处理回答的空间。此处评价路径与应答逻辑，实际互动质量仍由正式第6项评价。
- **理论建构自然度，2分**：2分为结论能追溯到前面辨析，学生表达、抽象与教师规范化的关系清楚；1—1.5分为能找到认识来源，但抽象或条件说明存在跳步；0.5分为只有教师总结，生成基础薄弱；0分为理论与问题链没有联系。此处看问题链的生成路径，不重复增设正式第7项分数。
- **迁移有效性，1分**：1分为简洁新条件要求使用同一学科认识并解释依据；0.5分为有实质条件变化，但依据要求或反馈标准不足；0分为没有迁移或只有原题复述。

实际课堂、模拟呈现、设计预评分别按其证据模式解释以上表现，不将预设认识修正当作实测。辅助维度可能观察到正式第4、6、7、8项也使用的课堂片段，但这里只解释第5项的问题设计机制，不能在100分体系外再次加分或扣分。方法中的问题数量建议也不新增正式限分规则。

## 十四、问题链质量自检表

逐项标记“通过／待修改／证据不足”，附节点编号或可核验位置；不要只打勾。认知功能合并实现可通过，缺少标题本身不算失败。

- [ ] 是否围绕一个核心教学问题？
- [ ] 是否明确学生的初始认识，并区分实际证据与预设？
- [ ] 是否至少有一次明显认知冲突，能指出原解释遇到的困难？
- [ ] 前一问是否为后一问提供认知基础？
- [ ] 是否包含比较、解释、判断、辨析等适合本问题的认知活动？
- [ ] 是否预留学生可能出现的不同答案，而非假定所有回答都与脚本一致？
- [ ] 是否为教师追问保留空间，并对应回答内容？
- [ ] 学生是否会经历有依据的观点修正或认识深化？
- [ ] 理论是否从前面问题中自然生成，必要补充是否明确说明？
- [ ] 是否有新的迁移任务，且仍使用本片段形成的认识？
- [ ] 是否避免问题过多、过碎，主问题与追问区分清楚？
- [ ] 是否符合约15分钟或章程规定时限，计入思考、回应、板书等时间？
- [ ] 学生回答是否真正影响追问、支架、比较或概括？
- [ ] 如果删除材料中的答案提示，学生是否仍需要思考？只移除直接泄露结论的提示，不移除推理必需的事实与证据。
- [ ] 六个认知功能是否均有承载位置，而非强行设置六个主问题？
- [ ] 若评分，是否同时读取正式评价标准，并区分辅助诊断分与正式第5项评分？

发现关键功能缺失，返回相应生成步骤局部修改；只有材料或实施证据不足时标待核验，不虚构成功结果，不继续创建其他方法文件或完整教案案例。
