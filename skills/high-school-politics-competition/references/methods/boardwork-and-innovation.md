## 一、基本定位与8分边界

本 Skill 正式评价中，“板书、创新与课堂特色”共8分：板书结构与生成性3分、教学设计创新3分、课堂特色与记忆点2分，不改变权重。

三者在比赛呈现中具有较强的可见性、区分度与记忆价值，但必须建立在核心教学问题明确、问题链合理、学生承担真实认知任务、教师追问有效及知识生成自然的基础上。不能用漂亮板书、技术形式或情绪感染掩盖教学逻辑不足。

本文件只设计和诊断三者，不重写已确认的问题链、认知活动与追问框架，不制作PPT模板或完整教案。整体课堂基础不足时，说明关联缺口，不能声称增加一个亮点即可修复整课。

设计预评、模拟呈现和实际课堂分别记录证据。预设板书生成与预期创新收益不是已发生的学生变化；最终截图也不能单独证明生成过程。

## 二、板书的核心定位：结果型与生成型

高质量比赛课板书是“学生认知发展和学科知识生成过程的可视化压缩”。它不应只是PPT复制品、教材目录，或从开课就完整展示的标准答案。

推荐的生成关系是：学生回答 → 教师提取关键词 → 继续追问 → 学生补充或修正认识 → 板书关系变化 → 最后形成理论结构。关键词可先记录，关系随回应逐步增加、连接或修正；结束时留下可复原核心逻辑的图示。此处完整指本片段的核心逻辑，不要求呈现45分钟整课全部知识。

### 1. 结果型板书

主要按既定知识顺序呈现标题或结论，如“含义—特点—判断标准”，看不出学生如何比较、遇到困难并形成认识。它可以有内容正确、便于回顾的价值，但不足以单独证明生成性。

问题不在教师提前知道结构，而在课堂书写与学生回答、追问及认识修正没有联系。不能把充分备课本身当作失分理由，也不能只因分三次写出三个标题就认定为生成型。

### 2. 生成型板书

内容与关系随学生判断、比较、冲突、追问和理论建构逐步增加、连接或修正，能够指出每个关键变化由哪一项认识触发。

例如，先记录不同主体及其判断依据，形成“主体条件—判断差异”的联系；再将“有差异是否就都合理”标为待检验问题，辨析后补出判断标准及其关系。不是把学生说出的词抄满黑板，而是留下认识如何发展的关键线索。

教师可以提前设计整体布局、候选关键词和回应分支，预留生成位置；实际或模拟呈现时应根据回应决定选词、连接与修正。预设框架与生成过程可以共存。

本 Skill 原则上优先推荐生成型板书。判断依据是内容来源与生成过程，不是教师是否临时即兴，也不是最终图形是否复杂。

## 三、板书与问题链、学生回答的关系

### 1. 与六步认知功能同步

板书不必机械写出六个阶段名称，但应保留重要认识变化：

| 六步功能 | 板书可以承载的内容 |
| --- | --- |
| 初判 | 主要观点或关键词，保留尚待检验的认识起点 |
| 析因 | 原因、条件、比较维度及其关系 |
| 冲突 | 用问号、对立位置、VS、中断连接或“≠”标出具体矛盾 |
| 辨析 | 补充条件、修正连接、排除不成立的解释 |
| 建构 | 规范学科结论及其逻辑关系 |
| 迁移 | 必要时留下一个新条件、关键词或检验结果，不强求全部写入 |

符号要说明含义。箭头用于因果、推理、时间或认识推进时须能区分，不能把“先后出现”画成“必然导致”；“≠”不能代替说明究竟哪个推论不成立。

如果板书生成顺序与课堂问题链完全无关，说明存在脱节。最终空间布局不必与发问顺序逐项一致，但每次新增或修订应能追溯到相应节点。

### 2. 从学生语言到学科语言

“重要板书关键词应尽可能来自学生思考结果。”记录学生表达中与本课认识推进有关的部分，再经追问、比较和概括转为规范表达；不要求所有学科术语都由学生独立说出。

教学示意：学生提出居民关注生活条件，可先记“居民—生活需要”；提出开发商关注收益、文保人员关注文化价值，可分别记录相应关键词。再比较这些诉求如何影响判断，才概括主体条件与判断差异的关系。不能因写出三种主体，就直接宣告已完成理论建构。

上述内容为可能回应，不代表同类主体必然持相同观点。应依据实际材料与回答取词，同一主体可以兼顾多种需要；不能把身份、立场与结论画成无条件一一对应。

用户示例中的“主体差异性”“客观规律＋人民立场”等，可作为相应课题的候选压缩关键词；正式概念、判断标准及其关系须核对所用教材与课标，不能把关键词组合当作完整教材原文或凭几个案例推得的全部理论。

### 3. 来源与修正可辨认

记录来源属于学生原话、教师准确转述、教师规范概括还是必要理论补充。不得把教师预设词伪称为真实学生答案。

不完整或错误观点若暂时上板书，标为“待检验”或用清楚标记区分，在收束前修正；不为保留所谓生成痕迹，让错误继续作为正确前提。适当预留空间，避免每出现一个意外回答就重画整板。

## 四、六类板书结构

按核心知识关系选一种主结构，必要时作小范围组合，不为展示多种造型拼接复杂图案。以下是抽象结构示意，不是完整学科板书案例。

### 1. 递进式

- **适用场景**：概念或认识逐层深化，需要显示前一步如何支持下一步。
- **示意**：现象 → 原因分析 → 解释困难 → 学科认识 → 运用；箭头在此表示认识推进。
- **优势**：顺序明确，便于逐步生成和回顾关键转折。
- **风险**：容易把所有知识硬排成一条线，忽略分支、反馈和适用条件。
- **不建议使用**：核心任务是多个维度的同时比较，或概念关系没有先后递进时。

### 2. 对比式

- **适用场景**：比较两个观点、制度、选择或不同主体的依据。
- **示意**：观点A及依据A ↔ 共同比较维度 ↔ 观点B及依据B，再汇聚到真正分歧。
- **优势**：同一维度对照直观，适合记录并处理学生观点差异。
- **风险**：版面对称不等于观点完全对立，不能预设非此即彼或双方同样合理。
- **不建议使用**：材料对象不具可比性，或主要内容是多环节机制而非观点比较时。

### 3. 因果式

- **适用场景**：经济、政治、哲学内容中需要解释有依据的机制关系。
- **示意**：条件 → 作用机制或原因 → 结果 → 影响，注明重要条件和反馈。
- **优势**：使“为什么”可见，防止仅罗列原因名称。
- **风险**：把相关当因果，把多因素作用写成单一因素必然决定结果。
- **不建议使用**：只有时间先后、分类或价值取舍而没有相应因果依据时；不得用因果箭头替代论证。

### 4. 矛盾转折式

- **适用场景**：原解释遇到边界，经冲突与辨析形成修正，是片段的主要转折。
- **示意**：原判断及理由 → 新条件下能否成立？ → 检验与修正 → 更有条件的认识。
- **优势**：突出学生认识改变的节点，便于保留疑问与修正痕迹。
- **风险**：只画大问号或“否”，却没有具体解释困难；把正确认识硬说成错误。
- **不建议使用**：没有自然认知冲突，或核心困难只是必要信息缺失时；应先检查教学问题，而非制造戏剧反转。

### 5. 总分结构式

- **适用场景**：一个核心原理或判断包含若干相关维度。
- **示意**：核心认识分出维度A、维度B，必要时补出二者联系与适用条件。
- **优势**：聚焦且便于压缩，能够在末尾清楚呈现理论结构。
- **风险**：退化为教材目录，或把相互关联的维度画成互不相关、任意选择的清单。
- **不建议使用**：最重要的是形成过程而分支图无法表现转折时；可以作为生成后的收束结构，不替代前面的认识线索。

### 6. 概念关系式

- **适用场景**：概念之间存在层级、包含、条件或其他明确关系。
- **示意**：概念A与概念B之间用标明“包含、条件、支持”等含义的连线表示关系。
- **优势**：有助于澄清边界和知识联系，避免学生只记孤立概念。
- **风险**：连线过多、图形拥挤，或不同关系混用同一种箭头。
- **不建议使用**：只有少数简单结论，或学生尚未明确概念且图示增加负担时。关系未核验不能先画成确定事实。

## 五、板书信息控制

采用“少而精”：保留核心概念、学生关键词、关键关系、认知矛盾和最终理论结构。避免写大段句子、完整教材原文、整套教学目标、所有案例细节，或把PPT已清楚呈现的长信息再抄一遍。

逐词做删除检查：删掉后是否损害核心概念准确性、关系判断或认识转折的理解？不影响时可以考虑不写。不能为少字删掉“不、并非、在……条件下”等决定结论边界的词。

标题可帮助定位，但不能成为全部板书。重复一个核心概念用于持续追踪是合理的，不把所有重复都视为无效。图示最后应能支持学生或观察者说明“解决了什么问题、如何形成认识”，而非只能评价字迹好看。

“信息压缩效率高”指较少信息保留关键逻辑，不额外制造字数比率或统一词数上限。缩写、符号和布局应让学生看得懂。

## 六、板书时间成本

生成板书时同时记录：什么时候写、写什么、在谁的哪类回答或哪次追问后写、预计耗时，以及对节奏的影响。无生试讲标为预设触发，不虚构真实学生发言。

计时包含转身、取笔、写字、画线、修改和必要解释，不能只计笔尖书写时间。可以与学生独立思考合理配合，但要实际可行，不能把同一时间重复用于教师倾听、复杂书写和口头追问。

板书总耗时须纳入约15分钟或具体时限，不能挤掉学生思考、教师追问和核心难点突破。没有试讲记录时用估计并标待核验；不设未经章程支持的统一分钟配额。

超时时优先删装饰、长句和重复信息，简化连线或布局，保留核心关系与转折。好的板书不是复杂，而是能用合理时间留下清楚的思维结构。

## 七、板书与PPT的分工

“PPT负责提供信息，板书负责留下思维。”这是功能分工原则，不是禁止任一载体承担其他必要功能。

- **PPT适合**：图片、视频、材料、数据、情境、较长文本和学习任务。
- **板书适合**：经过处理的学生关键词、学科概念、逻辑关系、认知变化与核心结论。

避免PPT已完整公布特点、标准和结论，教师再全部抄写而不产生新的关系或认识线索。若需持续引用关键术语，可以在板书保留，但须说明它服务哪一步分析。

按照赛事允许的载体设计，不把电子板书、幻灯片或手写形式本身当作生成性的证明；要看内容何时出现、如何受回答和追问影响。本文件不承担详细PPT设计，不创建模板。

## 八、Agent板书设计流程

先读取用户已有核心问题、问题链节点、学生产出与追问，不擅自重写已确认框架。缺少关键材料时只追问影响板书设计的必要信息，其他假设标明。

依次回答并记录：

1. 本课核心教学问题是什么？
2. 学生认知变化的关键节点是什么？
3. 哪些学生回答值得进入板书？
4. 哪些学科概念必须保留？
5. 概念之间是什么关系，依据是否成立？
6. 应采用哪种主结构，为什么？
7. 哪部分应预留给课堂生成或修正？
8. 哪部分可以提前写，是否符合比赛章程？
9. 板书是否与问题链推进同步？
10. 约15分钟或规定时限内能否自然完成？
11. PPT和板书是否存在无意义重复？
12. 最终板书能否让观察者快速说明本课核心逻辑？

随后生成：简洁最终结构草图、关键板书节点及生成顺序、预设与生成区分、用时合计和待核验项。草图与节点不得假装成已发生的实际板书过程；不额外生成整课教案或PPT。

已有板书的诊断则先还原原稿、生成时机与实际回答证据，再运行十二问。最终静态照片无法回答生成过程时，索取必要片段或标证据不足，不能直接判零生成性。修改只处理与当前问题相关的内容、关系、时机与时间成本。

## 九、板书节点标准格式

Agent应能按以下逻辑设计或内部检查，不要求所有正式教案都展示全部字段：

```markdown
### 板书节点：编号

- 出现时间：相对课堂节点或有依据的时间位置，关联主问题编号。
- 触发来源：学生回答／教师追问／理论概括；说明具体触发内容。
- 学生原话或关键词：实际记录、准确转述或预设，分别标明。
- 板书内容：真正需要写出的词、符号或关系。
- 板书位置：在整体布局中的位置及所需空间。
- 与已有内容建立的关系：新增、连接、补条件或修正，说明符号含义。
- 教学作用：保留什么认知成果，帮助下一步完成什么分析。
- 是否为生成性内容：是／否；依据是什么，不以分次书写自动判是。
- 预计耗时：计入书写、连线、修改与必要解释，标估计或实测。
- 依据与证据状态：材料和理论来源；区分设计预期、模拟与实际课堂。
```

若触发来源是教师必要理论补充，学生原话字段写明“不适用，教师补充”，不编造一个学生来提供术语。最终关系要能回到核心问题，不为每个回答强行新增一块板书。

## 十、教学创新的定位与弱创新

“创新不是课堂里出现了以前没有的东西，而是教学问题被更有效地解决。”这里评价针对本课困难的设计改进，不要求证明全国首创或从未有人使用过。

每个创新候选须说明相较什么常见或现有方案，改善了哪一步：是否更易暴露真实认识、使问题链自然衔接、促使学生思考、突破难点、提高建构质量或形成有学习价值的辨识度。没有比较依据时写“预期改进”，不宣称已证明优于其他课堂。

**弱创新或尚未证明创新价值的形式变化**包括：换热点、播新视频、使用AI、二维码、投票、游戏、角色扮演、情境剧、数字人或其他技术工具。这些形式本身既不是高分依据，也不自动是坏设计。

只有能够说明并提供相应证据，证明形式如何改善学习过程，才体现创新价值。例如投票若只增加点击，价值有限；若成为比较判断依据和检验认识变化的材料，才可能产生认知作用。不是把所有投票一律判为强创新。

## 十一、七类强创新

以下是设计改进的可能位置，不要求一课全部具备。名称中写了“冲突、追问、活动机制”也不自动成立，仍须通过必要性和效果证据检验。

### 1. 教学问题切口创新

从内容中找到有价值的认识困难，而不是仅询问知识名称。例如从“价值判断有什么特点”转向检验“既然各有判断，是否还能评价其合理性”。后者也必须有适合的学生起点、材料和分析空间，不能只因问句有张力就判创新。

**生成与判断**：写明它替换了哪个宽泛问题，暴露什么误解，为什么值得用本片段解决。

### 2. 情境结构创新

改进情境内部的信息、条件与变化，使它持续支持初判、析因、冲突、辨析和建构，而不只选更新的材料。

**生成与判断**：说明每次条件变化如何依赖前面认识；若各环节仍是无关案例拼接，材料新鲜不等于结构改进。

### 3. 认知冲突创新

找出合理但不完整的解释，用相关反例或条件变化检验其边界，推动修正或深化。

**生成与判断**：记录原解释、检验条件和新的认识需要；不伪造事实，不强迫正确回答先变错，也不把戏剧性反转等同于认知冲突。

### 4. 学生活动机制创新

用排序、选择、立场转换、证据判断、观点评审等机制，让学生更清楚地承担比较、判断或论证。

**生成与判断**：先确定认知产出和交流必要性，再选形式；说清机制改变了什么思考，而非只增加分组、规则或操作步骤。

### 5. 教师追问创新

依据学生原话中的关键词、矛盾或不足，选择有针对性的下一问，改善认识推进。

**生成与判断**：指出哪一种回答触发何种追问，预期得到什么修正；不是追问句式少见、层数多就有创新。

### 6. 理论表达创新

将抽象认识组织为清晰、有逻辑、有记忆度的表达，同时保留学科含义和条件。

**生成与判断**：核验表达是否帮助解释关系、是否有前面的分析基础；比喻或简写不能替代理论，也不能为了好记改变概念含义。

### 7. 板书结构创新

通过恰当结构清楚呈现矛盾、转折、因果或概念关系，使学生认知变化可见。

**生成与判断**：比较新旧结构保留的思维线索与时间成本；新造型但未改善理解，不算强创新。

## 十二、创新必要性检验

对每个创新候选依次记录：

1. 它解决什么具体教学问题？
2. 删除它，课堂会损失什么？
3. 它是否增加学生的思考，而不只是动作？
4. 是否只是增加课堂形式？
5. 是否增加准备、操作或课堂时间成本？
6. 是否影响15分钟节奏？
7. 是否与核心议题有关？
8. 是否与问题链有关？
9. 是否有助于观察者看见学生认知及其变化？
10. 是否存在更简单、更有效的方式？

删除后若关键思考、产出与认识推进几乎不变，创新价值较低。若另一种更简单方式能获得相同收益，应说明保留复杂形式的必要理由；没有理由则简化。删除检验针对主要机制，不把每个装饰细节都要求成不可替代。

设计记录至少包含“拟解决问题—原有方式—改进机制—预期认知收益—证据或待验证项—成本—保留或简化决定”。实际学习改进需要实施证据；模拟过程不能替代效果验证。

## 十三、比赛课的创新过载

视频、AI、小组合作、投票、辩论、情境剧、二维码同时出现，可能使操作与切换挤掉学生思考、教师追问和理论生成。问题是成本与认知收益不匹配，不是某几种形式一同出现就自动违规。

15分钟比赛课通常聚焦1—2个真正有价值的创新点即可。这是取舍建议，不是官方数量上限或新增评分门槛。一个有张力的问题与一个能推进认识的冲突，可能比多种技术手段更有效。

把围绕同一困难配合工作的工具与步骤视为一个机制整体，避免拆成多个“亮点”凑数量。按认知收益、必要性和时间成本排序，优先保留核心改进，减少装饰性操作。

## 十四、课堂特色及其八种来源

课堂特色是在学科规范与教学有效性基础上形成的稳定辨识度，不是为了不同而不同。可以用“这是那节通过……帮助学生理解……的课”概括其候选记忆点，但不能代替真实评委宣称一定会记住。

特色可以来自：

1. **核心问题**：有张力且容易复述，指向具体认识困难。
2. **主情境**：有现实复杂性，并以必要信息贯穿学习，而非故事堆砌。
3. **问题链结构**：前后依赖自然，认识推进路径可清楚说明。
4. **高价值追问**：利用学生表达，使其修正或深化认识。
5. **教师语言**：简洁、准确、有理论解释力，符合教师自己的表达习惯。
6. **理论升华**：基于前面思考形成概括与价值认识，而非突然喊口号。
7. **板书**：留下能复原思维过程的逻辑结构。
8. **学生活动机制**：学生以清楚方式完成判断、比较或论证，产出被用于后续推进。

教师个人思考应体现在取舍、材料处理、回应方式和理论联系的理由中，不是添加口头禅、私人故事或夸张表演。未了解教师实际表达风格时，只提供可选择的表达，不虚构其个人经历或“专属风格”。

## 十五、记忆点设计与真实性检验

可以尝试安排1个主记忆点和1—2个辅助记忆点，如以核心认知冲突为主，以一次有价值的追问和生成性板书为支持。数量是帮助聚焦的建议，不必为了填满配额再造亮点。

让几个记忆点服务同一核心问题。若每个环节都争夺注意，观察者可能难以辨认真正重要的内容；“亮点过多”是过载风险，而不是可以脱离任务证明的普遍定律。

**真实性检验**：

- 为什么可能被记住？高质量回答能指出它帮助学生解决了哪一个问题、怎样改变认识；“PPT漂亮、用了新技术”单独不足以证明教学价值。
- 能否指出对应的问题、学生产出、追问或图示，而不只是“有特色、很震撼”？
- 如果删掉教师姓名，这节课与其他AI生成的高中政治比赛课有什么明显区别？用具体设计取舍回答，而不是评价某种固定文风。

有用户提供的其他方案时可在相同维度上比较；没有比较材料时，只做匿名辨识和常见模板风险检查，不能声称查遍其他AI教案或证明独创。也不能根据语言模板化就断定内容由AI生成。

如果去除姓名与工具品牌后，只能复述通用流程、找不到具体教学贡献，说明特色证据不足。优先强化已有核心问题的独特处理，不为了区别而另加任务。

## 十六、课堂特色的学科规范

创新以概念准确、理论准确、价值导向恰当、材料真实、逻辑严谨为前提。依据所用教材、课标和已核验材料说明相关结论，不把个人表达当作原文。

不能为了比赛效果夸大真实事件、故意制造错误事实、把复杂政治问题简化为笑料，或用热梗、情绪替代理论分析。使用比喻、游戏或角色形式时，说明其分析对象和边界，不能让形式改变事实与概念含义。

教学假设或虚构情境须标明性质，内部条件应一致，不伪装成真实新闻。未核验数据与出处保留待核验状态；创新设计尚未试讲时，只说明预计收益，不宣称已提升学习效果。

## 十七、理论升华：怎样避免突然拔高

如果前面只讲一个知识点，结尾突然添加“为中华民族伟大复兴贡献青春力量”等动员性表达，却说不清与学生分析的联系，就可能是突然拔高。问题在于逻辑断裂，不是仅凭一句话的字面判断其是否适用。

自然的路径是：学生解决具体问题 → 形成学科认识 → 说明其中的价值意义 → 在适当范围联系现实 → 形成有依据的价值提升。

Agent写结尾前先定位：它接续哪一个已形成的认识？哪项事实、理由或标准支持价值判断？更广现实联系是否仍在本课可解释范围内？如果无法回答，缩回本片段能够支持的结论。

允许用简洁、有温度的语言表达，但不能靠情绪弥补缺少论证。15分钟内不强求宏大升华，准确说明一个学科认识如何帮助判断现实问题，也可以形成有价值的收束。

## 十八、板书、创新与特色的协同

三者不应成为教学结束后附加的三个孤立模块：

```text
核心教学问题
→ 有张力且合理的问题链
→ 学生认知活动（如比较、判断、辨析、论证）
→ 学生回答，显露当前认识与依据
→ 教师依据回答追问，引导补充、比较或修正
→ 板书生成，提取关键词并呈现关系变化
→ 板书使认识推进及最终理论结构可见
→ 形成有依据的课堂结构与辨识度
→ 产生值得保留的候选记忆点
```

核查每个关键板书节点时，追溯“问题链 → 学生认知活动 → 学生回答 → 教师追问 → 板书生成”的具体证据。这是可以往返的互动关系，不要求每次回答都写板书；不能另起一个脱离学生思考的板书活动模块。

最有价值的创新可能就是一个解决困难的问题链；课堂特色也可能来自自然的生成性板书。无需为每个模块另外设计一个活动。追溯不到认知变化时，先说明缺口，不在本任务中擅自重写其他方法框架。

**Agent协同交付**：根据用户本次范围，给出板书结构与生成节点、1—2个创新候选及必要性判断、一个主记忆点与可选支持点，标出它们共同服务的认知问题。附成本、证据状态及最小修改建议，不扩成完整教案或PPT模板。

## 十九、8分内部辅助评分

### 1. 权重与正式评分的关系

| 子项 | 满分 |
| --- | ---: |
| 板书结构与生成性 | 3 |
| 教学设计创新 | 3 |
| 课堂特色与记忆点 | 2 |
| **合计** | **8** |

沿用 [competition-rubric-100.md](../rubrics/competition-rubric-100.md) 第10项的3＋3＋2分，不改变100分体系。

以下按用户指定的整数档位作内部辅助诊断。正式第10项仍以原评价文件的0.5分档位、证据规则和子项描述计分；整数辅助分不替代正式分，不机械四舍五入，也不能额外加到100分中。两套描述的粗细不同，例如本节板书2分包含部分生成性，不能据此覆盖正式2分与2.5分的区别；报告须明确采用哪种口径。

需要最终评分时读取正式评价文件；辅助分仅在有助于定位改进时另列。内容正确、表达流畅或形式美观不能抵消原评价文件规定的高分限制，本文件不新增限分规则。

### 2. 板书结构与生成性（3分）

- **3分**：与问题链高度融合，能定位回答、追问与书写的触发关系；生成过程清楚，结构简洁，显示重要认识变化，结束时可据图概括本片段核心逻辑。
- **2分**：结构基本清楚，与教学内容一致，有部分生成性，但对学生认识修正或关系形成的呈现较常规、不够充分。
- **1分**：主要是标题和教材知识罗列，与学生回答及认知过程联系弱；并非所有含标题的板书都归此档。
- **0分**：完整证据确认没有有效板书功能，或内容明显混乱、错误，无法支持相关理解。没有提供板书照片不等于本项0分。

### 3. 教学设计创新（3分）

- **3分**：能定位设计直接改善问题发现、认知冲突、学生思考或难点突破的机制，且时间与操作成本合理；设计预评只认定预期机制，不冒充实测收益。
- **2分**：有针对本课问题的设计特色，但学习改进有限，或对作用与实施条件的说明不充分。
- **1分**：主要表现为素材或技术形式变化，尚不能说明认知过程获得了何种实质改进。
- **0分**：没有可辨认的设计改进，或形式变化反而明显损害核心学习。未使用技术工具本身不是0分理由。

### 4. 课堂特色与记忆点（2分）

- **2分**：至少一个候选记忆点与教学逻辑高度结合、辨识度明确，能具体描述其对解决认识问题的作用。
- **1分**：课堂规范，有一定相关特色，但主要依赖素材或常见表达，辨识度与教学贡献有限。
- **0分**：只能描述通用流程或外观，无法指出可记忆的具体教学特征。不能虚构真实评委“没有记住”的心理。

### 5. 证据处理

实际课堂、模拟呈现、设计预评分别标明。缺少过程录像、材料或必要上下文时，标待评，不将缺证据记0分，不按其余子项折算8分；可以说明已有证据支持哪些判断、仍缺什么。

同一设计可以同时体现板书生成、创新和记忆价值，但要分别说明三种功能，不以一个“亮点”在三项自动满分。辅助分未经实际评分一致性校准，不将小分差解释为客观精确测量。

## 二十、十五类失败表现

### 1. 板书复制PPT型

- **典型表现**：把屏幕文字再抄一遍，没有增加关系或认知线索。
- **问题原因**：占用时间，未体现两种载体分工。
- **修改方向**：PPT保留信息，板书提取关键概念、比较关系与修正结果；允许必要术语持续出现。

### 2. 教材目录板书型

- **典型表现**：只有含义、特点、意义等标题。
- **问题原因**：显示知识栏目，却没有认识形成的路径。
- **修改方向**：围绕关键问题补出学生判断、分析关系和转折，不机械删除一切标题。

### 3. 提前公布答案型

- **典型表现**：讨论前完整板书理论结论，学生只寻找匹配表达。
- **问题原因**：可能泄露需要学生完成的推理，生成过程退化为确认。
- **修改方向**：保留必要定位或框架，延后关键结论并写明其触发依据；提前备课本身不算失误。

### 4. 板书与问题链脱节型

- **典型表现**：按另一个知识顺序书写，与当前回答和追问无关。
- **问题原因**：视觉记录不能支持正在发生的认识推进。
- **修改方向**：关联主问题和活动编号，重排生成时机；空间布局不必机械等同发问顺序。

### 5. 板书过多拖慢课堂型

- **典型表现**：长句与案例细节过多，思考和反馈被挤掉。
- **问题原因**：书写成本超过对学习的贡献。
- **修改方向**：压缩为关键词和必要关系，保留限定条件，重新试讲计时。

### 6. 追求复杂造型型

- **典型表现**：造型精致、连线密集，学生难以读懂。
- **问题原因**：视觉复杂度遮蔽知识关系。
- **修改方向**：依据真实关系选主结构，删装饰和无含义线条，不把形状新奇当作创新。

### 7. 技术工具等于创新型

- **典型表现**：以使用AI、二维码或数字人为唯一亮点说明。
- **问题原因**：工具出现不能证明学习改善。
- **修改方向**：说明改变了哪一步认知、收益与成本；没有贡献时简化或移除。

### 8. 热点材料等于创新型

- **典型表现**：材料新，但问题仍是原有知识问答。
- **问题原因**：信息时效没有转化为任务价值。
- **修改方向**：核验材料后提取真正的条件、冲突和判断空间，不为追热点偏离目标。

### 9. 创新堆砌型

- **典型表现**：多种形式连用，每项都需规则说明和切换。
- **问题原因**：认知任务碎片化，15分钟内缺少充分处理。
- **修改方向**：按必要性保留1—2个核心机制，减少形式转换；数量只作取舍提示。

### 10. 活动花哨但无认知价值型

- **典型表现**：游戏、表演或投票热闹，结束后没有判断依据或新认识。
- **问题原因**：行为参与替代认知产出。
- **修改方向**：追溯任务、产出和后续用途；无法建立联系时改变或取消形式。

### 11. 为特色而特色型

- **典型表现**：为与别人不同，添加与本课困难无关的桥段。
- **问题原因**：辨识度来自装饰，甚至干扰学科理解。
- **修改方向**：从已有核心问题的独特处理形成特色，不另造支线。

### 12. 模板化升华型

- **典型表现**：结尾换到任何课题都能使用，没有回应本课具体认识。
- **问题原因**：语言没有承载学生学到的关系或判断依据。
- **修改方向**：引用本课已形成的认识与价值意义，保留教师自然表达。

### 13. 突然价值拔高型

- **典型表现**：从局部知识直接跳到宏大结论，中间缺少分析支撑。
- **问题原因**：价值判断与课堂推理断裂。
- **修改方向**：补足可支持的联系，或缩回本片段能够成立的结论，不用情绪填补逻辑。

### 14. 课堂亮点过多型

- **典型表现**：每个环节都单独造高潮，观察者难辨核心问题。
- **问题原因**：多个注意焦点相互竞争，主线被稀释。
- **修改方向**：确定一个主记忆点，其他设计作为支持，不要求每处都新奇。

### 15. AI味过重、缺少教师个人辨识度型

- **典型表现**：只有可替换课题的套话、通用活动和无具体理由的“精彩升华”。
- **问题原因**：看不到教师对学生困难、材料与回应的实际取舍；不能据此认定作者一定使用AI。
- **修改方向**：补出教师自己的设计理由、材料处理与应答选择；有对照材料时再比较，不杜撰个人经历或强加文风。

## 二十一、三个质量检查器

统一处理方式：记录“通过／待修改／证据不足”及位置，不只打勾。先核验任务和材料，再给局部修改方向；资料不足不直接认定教学功能缺失。检查标签不新增评分或扣分规则。

### 1. 板书质量检查器

1. 板书服务哪个核心教学问题？
2. 它体现哪几个认知变化？
3. 哪些内容来自学生回答，证据是什么？
4. 哪些内容由教师规范概括或补充？
5. 是否体现问题链逻辑？
6. 是否以恰当符号或关系呈现认知冲突，而不只是加问号？
7. 是否简洁且保留概念边界？
8. 是否与PPT无意义重复？
9. 15分钟或规定时限内能否自然完成？
10. 最终能否快速说明课堂核心结构？

**输出**：问题位置、来源或关系缺口、保留与删改内容、调整后的生成时机及待核验用时。最终照片只能支持终态判断，生成性还需过程或设计证据。

### 2. 创新质量检查器

1. 它解决什么教学问题？
2. 为什么采用这种方式？
3. 是否增加学生认知参与？
4. 是否推动问题链？
5. 是否有助于重难点突破？
6. 是否存在更简单的方法？
7. 时间成本是否合理？
8. 删除后课堂的关键认知路径是否明显变弱？

若第1、3、4、8项均无法说明，创新价值较低；若只是部分关键项不清，记录待验证的作用，不靠“新颖”补足。资料缺失时不能声称已证明没有效果。

**输出**：改进对象、认知作用、成本、证据状态，以及保留、简化或取消建议。不以未使用技术或没有罕见形式直接判无创新。

### 3. 课堂特色检查器

1. 本课最值得记住的是什么？
2. 为什么值得记住？
3. 是否源于教学逻辑，而非装饰？
4. 与所提供的常见或AI方案相比有何具体不同？没有对照时能否说明自身的独特取舍？
5. 是否体现教师个人思考，而非仅有姓名或语言习惯？
6. 是否建立在学科准确性基础上？
7. 如果只能保留一个亮点，应保留哪个？

**输出**：一个主要候选记忆点、教学依据、可选辅助点及需要删除的竞争性装饰。没有真实评委反馈时只谈可能记忆价值，不宣称已获认可。

## 二十三、板书、创新与课堂特色自检

逐项记录证据或设计依据，区分预期、模拟与实际表现：

- [ ] 板书是否体现学生认知推进？
- [ ] 板书是否随关键回答、追问或概括逐步生成？
- [ ] 是否避免只有教材目录式罗列？
- [ ] 板书生成是否与问题链同步？
- [ ] 是否足够简洁，同时保留重要条件和否定关系？
- [ ] 板书与PPT是否合理分工？
- [ ] 创新是否真正解决具体教学问题？
- [ ] 是否避免技术工具堆砌？
- [ ] 是否优先控制在1—2个核心创新点，超出时有明确必要性？
- [ ] 创新是否增加学生思考，而非仅增加操作？
- [ ] 是否形成至少一个有依据的候选课堂记忆点？
- [ ] 记忆点是否来自课堂逻辑？
- [ ] 是否避免突然价值拔高？
- [ ] 是否体现一定个人思考与辨识度，而非仅靠姓名或套话？
- [ ] 是否适合15分钟或规定时限，并计入板书成本？
- [ ] 是否能帮助观察者快速理解本课教学特色？
- [ ] 如涉及评分，是否区分整数辅助档位与正式0.5分评分，未改变3＋3＋2分权重？

最后回答三个核心诊断问题：

1. 如果去掉PPT特效，这节课的创新还剩什么？
2. 如果删掉教师姓名，这节课与其他AI生成比赛课有什么区别？没有对照材料时说明自身的具体取舍，不声称已作全面比较。
3. 如果评委只能记住这节课一个东西，我希望他记住什么？说明教学依据，不猜测真实评委心理。

完成当前设计或诊断后停止，不继续创建其他方法文件、完整教案案例或PPT模板。
