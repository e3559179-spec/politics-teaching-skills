## 一、基本定位：从行为层进入认知层

“学生参与”不等于“学生很忙”。看视频、读材料、小组讨论、举手回答、角色扮演，都不天然等于高质量学习。

课堂活动的价值，不只看“做了什么形式”，而看“学生的大脑在做什么”。操作上应依据任务要求、学生表达、作品和回答处理过程判断认知操作与变化，不能直接读取或臆测学生内心。任务要求了思考，不等于学生已经完成；一次正确回答也不足以证明全体学生都已理解。

**行为层**描述学生表面上做了什么：看、读、写、说、讨论、投票、表演、汇报。这些是学习载体，不自动说明认知深度。

**认知层**描述学生处理信息的操作：识别、提取、分类、比较、排序、归因、解释、推测、选择、判断、质疑、反驳、辨析、论证、概括、抽象、评价、迁移、反思。操作名称仍须带上对象、依据及产出，不能只把“讨论”改名为“高阶辨析”。

同一种行为可以承载不同深度的任务。例如阅读材料既可能只是寻找教材原句，也可能要求比较三个主体的利益立场、识别矛盾并解释原因。不得仅凭活动名称判断参与质量。

将低信息量的活动描述改为可检查的任务：

| 原描述 | 可检查的认知描述 |
| --- | --- |
| 学生观看视频 | 学生从视频中提取不同主体的诉求，并指出所依据的信息 |
| 学生阅读材料 | 学生比较不同立场及其形成条件，找出关键差异 |
| 学生讨论 | 学生判断两种观点的合理性，分别说明依据与适用条件 |
| 学生回答问题 | 学生质疑原解释是否充分，说明需要补充的条件 |
| 学生总结 | 学生从案例比较中概括关系，再用新标准重新评价案例 |

左侧描述本身只是信息不足，不能单凭简写认定真实课堂低效。设计时补齐，评价时索取或核验实际任务与产出。

## 二、四层认知活动分类

四层按主要思维要求组织，作为本 Skill 的内部分析工具。实际深度取决于对象复杂度、前置知识、理由要求和支架，不能按动词机械定级。同样是“判断”，凭直觉选边与综合证据检验结论的认知要求不同；“推测”若只是猜测不算充分分析，有条件与证据才可评价其质量。

### 第一层：信息获取与识别

- **包括**：观察、识别、提取、描述、复述。
- **功能与适用场景**：进入情境、获得事实、识别后面分析必需的信息。适合初读材料、确认主体与条件、澄清关键事实。
- **生成要求**：明确提取对象、筛选标准及信息用途，如“找出支持两种判断的事实”，而不是“把材料读一遍”。
- **认知产出**：相关信息清单、准确描述、事实与观点的初步区分等，可被下一节点直接使用。
- **低效表现**：摘录所有文字；反复复述不进入分析；找到教师划好的句子就宣布理解了理论。
- **提升方向**：将提取结果交给下一步比较或解释，减少重复确认。此层必要，但课堂长期停留于此会成为材料复述课。

### 第二层：分析与组织

- **包括**：分类、比较、排序、联系、归因、解释、寻找条件、区分立场。
- **功能与适用场景**：从现象进入关系与原因，是高中政治问题链中常见且必要的工作。适合分析同一问题为何有不同判断、区分事实条件及解释差异。
- **生成要求**：给出或让学生发现比较维度、分类依据、因果条件；要求说明信息之间怎样关联，而不只列出不同点。
- **认知产出**：比较结果、分类及标准、原因与条件的联系、可供检验的解释。
- **低效表现**：分类没有依据；“因为想法不同，所以判断不同”只是重复现象；把主体身份直接当作唯一原因。
- **提升方向**：用反例或条件变化检验已形成的解释，使分析成为判断与论证的基础。

### 第三层：判断与论证

- **包括**：判断、选择、质疑、辨析、反驳、论证、评价。
- **功能与适用场景**：处理不同观点、立场及价值选择间的冲突，检验什么解释更合理、依据是什么。应成为比赛课中重要的高阶认知活动。
- **生成要求**：保留真实解释空间，明确判断对象、证据和必要标准；学生应比较理由、检查前提或回应不同解释。
- **认知产出**：有依据的判断、对解释边界的质疑、反驳理由、修正后的观点及成立条件。
- **低效表现**：只投票不讲依据；猜教师答案；用多数人赞成代替论证；把不同意见都说成“有道理”而不分析。
- **提升方向**：追踪判断如何受到证据支持或被反例修正，并把成立的关系交给后续概括。初判中的直觉选择未必已达到本层深度。

### 第四层：建构与迁移

- **包括**：概括、抽象、建模、形成规则、理论建构、迁移、反思。
- **功能与适用场景**：从具体材料上升为学科概念、原理或判断标准，并重新运用；适合辨析后的理论生成、简洁新情境应用及认识变化回顾。
- **生成要求**：让学生说明从哪些比较结果形成什么一般关系，教师进行必要规范化；再改变关键条件检查运用。建模可只是清晰表达关系及条件，不必增加复杂图表。
- **认知产出**：有条件的概括、规范理论表达、可使用的关系或规则、新情境判断、对原有理由的修正说明。
- **低效表现**：教师端出理论让学生抄写；由一个例子直接推出无条件普遍结论；迁移只换人名；反思只写“收获很大”。
- **提升方向**：检查结论依据、适用边界和新条件下的使用方式，区分学生已形成的认识与教师补充的理论。

优秀的15分钟比赛课原则上不应只停留在前两层，至少要能辨认“分析或判断 → 辨析或论证 → 概括或迁移”的推进。该表述是认知升级的检查线索，不删减六步模型要求的认知功能，也不要求每一种活动都出现。

## 三、与六步问题链的对应关系

六步模型负责课堂认识如何推进，认知活动描述学生在每一步具体做什么思维工作。两者配合使用，不更改“初判—析因—冲突—辨析—建构—迁移”的结构，也不机械一一绑定。

| 六步功能 | 常见认知活动 | 核心检查问题 |
| --- | --- | --- |
| 初判 | 选择、判断、解释初步理由 | 学生原来怎么想？ |
| 析因 | 比较、分类、归因、解释、联系条件 | 为什么形成这种现象或差异？ |
| 冲突 | 质疑、发现矛盾、比较反例、检验原解释 | 原来的认识够不够？ |
| 辨析 | 判断、辨析、论证、反驳、条件分析、修正观点 | 哪种解释更合理？为什么？ |
| 建构 | 概括、抽象、形成规则、理论表达 | 可以形成什么学科认识？ |
| 迁移 | 应用、评价、决策、解释新问题、迁移判断 | 新认识能否解决新问题？ |

同一认知活动可以跨阶段出现，同一活动节点也可承担相邻的多个认知功能。例如比较既可寻找原因，也可检验反例或辨析依据；具体功能由该节点在整条链中的作用决定。

## 四、认知活动设计的标准结构

每个有学习目的的活动节点至少记录九个核心字段，并补充用时与证据状态以支持实施：

```markdown
### 活动节点：编号

- 活动名称：简洁描述本节点任务。
- 所属问题链阶段：认知功能及对应主问题编号，可合并相邻功能。
- 教学情境：完成任务所必需的信息与条件。
- 学生外显行为：阅读、写作、交流、投票等载体。
- 学生核心认知活动：操作＋对象或依据，不只列动词。
- 认知对象：比较什么、判断什么、解释什么关系。
- 认知产出：具体结果，以及相对起点增加、修正或深化了什么。
- 教师支持方式：学生卡点、必要支架，以及如何利用产出继续推进。
- 与下一环节的关系：本产出为后问提供什么基础或未解困难。
- 预计用时：计入阅读、思考、交流、反馈与板书，不重复计时。
- 依据与证据状态：材料来源、学情假设、可能回答；
  区分设计预期、模拟呈现和实际课堂证据。
```

活动节点与六步文件中的问题节点使用相同编号或明确对应关系，不另建一套平行课堂。一个活动可处理主问题及其必要追问，不要求一问配一个新活动。收束节点说明如何反馈迁移结果，不为填写“下一环节”另开课题。

### 单活动记录示意

以下只是记录格式示意，城市更新信息与学生回答均为教学预设，不构成完整教案、真实调查或教材原文引证。

- **活动名称**：比较三方城市更新方案。
- **所属问题链阶段**：析因，承接上一节点的初步方案选择。
- **教学情境**：提供同一城市更新事项中三方观点及支持理由的简短信息；实际使用时补充来源，不能只给身份标签让学生猜立场。
- **学生外显行为**：阅读三方观点并交流比较结果。
- **学生核心认知活动**：比较不同诉求及判断依据，归因并分析条件。
- **认知对象**：居民、开发商、文保人士可能提出的利益诉求与理由；同类主体不必持同一观点，同一主体也可能兼顾多种需要。
- **认知产出**：从“每个人想法不同”推进到用材料解释立场、利益、需要等条件如何影响判断；不据此推出所有判断都合理。
- **教师支持方式**：必要时提供比较维度，引导学生说明归因依据；用不完整回答确定需要进一步澄清的条件。
- **与下一环节的关系**：为检验“不同判断是否都合理”提供已有解释及其边界。
- **预计用时**：依据实际材料与交流要求估计并试讲核验，此示意不虚构实测时间。
- **依据与证据状态**：预设任务与预期产出，实际学习结果待课堂证据验证。

## 五、活动必须有认知产出

任何学生活动都必须明确一个认知产出。可表现为一组比较结果、一个分类、一个判断、一个观点及理由、一个争议点、一个被否定或修正的原认识、一个概括、一个理论表达或一个迁移结论。

每次设计后回答：“学生因此多知道了什么、多理解了什么、改变了什么？”若只能答“完成讨论、看完视频、参与投票”，需要重新设计。初判也有产出：使原有判断及理由明确，成为后续检验的起点；不要求每个节点立刻生成新理论。

产出不必都是长篇书面作品，可以是有依据的口头表达、关键词、比较标记或简短判断。不能为留痕让15分钟变成填表课；也不能因学生没有发言，就推断其没有思考。评价需核验可获得的认知证据，缺证据时明确限制。

设计中的“预期产出”与课堂中的“实际产出”分别记录。教师写好了理想答案不等于学生已经形成该认识；一个学生的回答也不自动代表全体学生。

发材料、切换设备等组织动作不单列为认知活动节点，其时间计入课堂安排；学习活动才需要逐一说明认知功能和产出。

## 六、高互动 ≠ 高认知

典型的低认知高互动包括：

- 抢答很多，但只需复述材料。
- 小组讨论很多，但任务没有需要比较或共同解决的认识问题，理由没有被处理。
- 投票很多，却不要求说明理由。
- 角色扮演很热闹，却不产生概念理解或观点分析。
- 学生频繁回答“是、不是”，不承担判断依据的分析。
- 教师不断邀请参与，学生只是重复教师观点。

高质量互动应根据任务承担其中若干功能：要求学生作判断、提供依据、处理不同观点，允许有理由的不同答案；教师根据回答继续追问，学生观点影响后续处理；学生能够修正认识，或在新情境中使用知识。不是每个节点都必须完成全部功能，但整条链须有可辨认的认知推进。

没有不同结论不自动等于讨论低效：学生可能比较了不同理由、发现同一结论的条件或排除了错误解释。评价的是实际思考与产出，不以争论声量或意见数量作标准。

## 七、认知活动密度：少而深

“认知活动密度”指有限时间内主要节点是否持续承担有意义的认知任务，不定义为每分钟活动数、发言数或动词数量，也不额外制定量化评分公式。

约15分钟默认围绕一个主情境安排3—5个主要认知活动节点即可。一个可用的功能组合是：初步判断 → 比较和归因 → 处理认知冲突 → 辨析并建构理论 → 迁移应用。它是节点组合示意，不改变六步结构，不强制固定五个活动；相邻功能可合并，迁移可在主情境中改变条件或使用简短新材料。

避免一个视频算一个活动、一页PPT算一个活动、不断切换形式、5分钟内堆放多个来不及处理产出的小组任务，以及每个活动都停留于表面。数量建议不是官方上限，超过推荐数量不自动扣分，先检查是否存在碎片化和时间挤压。

逐节点核算阅读、独立思考、交流、教师反馈和板书时间；再补计未覆盖的导入与转场，避免在问题节点和活动节点中重复计时。超时时优先合并重复提取、减少装饰材料与形式切换，不用取消思考、跳过回答处理或宣布“大家讨论得很热烈”换取按时结束。

## 八、学生认知活动必须逐步升级

可用“提取 → 比较 → 归因 → 判断 → 质疑 → 辨析 → 概括 → 迁移”检查整段学习的认识走向，不将其变为八个固定活动或新增方法模型。避免整节课只是“提取 → 提取 → 复述 → 回答 → 再复述”。

Agent设计时逐对检查：后一个活动是否使用前一活动产出，并让学生处理更深入的关系、条件、依据或应用？若只是换材料重复同一操作，说明重复对突破难点有何必要；无法说明时合并或重设。

“逐步升级”要求整体推进，不是每一分钟都单调增加难度。辨析前可返回材料核验事实，建构后可简洁概括，迁移可以在支架支持下完成；这些回看和收束只要服务于认识深化，就不算退步。也不能仅凭后面用了“评价”一词就认定已升级。

低门槛进入、适度分析、关键处辨析与论证、形成认识后再运用，应与学生起点和15分钟尺度相符。认知升级可以是原观点修正，也可以是正确观点的理由完善、条件明确或适用范围扩大，不强迫学生先答错。

## 九、教师为学生认知提供支架

教师不是退出课堂，而是帮助学生完成尚不能独立完成的认知工作。可以提供材料、设置任务、明确比较维度、提供思考框架、追问依据、引入反例、组织观点比较、板书关键词、帮助概括和规范理论表达。

“教师支持应该解决学生‘暂时做不到’的问题，而不是替学生完成本来能够完成的思考。”

设计支持时依次记录：学生可能卡在哪里、需要哪一种最小帮助、提供后仍由学生完成什么分析。比较维度可以由教师给出，也可由学生发现；选择取决于目标、起点与用时，不以“全由学生发现”为唯一高水平标准。

教师不应包办关键分析、开始即公布结论、每次回答后立即宣布标准答案，或把讨论变成下一段讲授的过场。必要的事实澄清、概念纠偏和理论规范化可以直接说明，但要区分它们与学生应承担的判断任务。

判断支架是否过度：若提示已包含全部依据及结论，学生只需补最后一个词，应减少代答；若学生因缺少必要事实完全无法进入，也应补充信息，不能把无从下手当作高阶挑战。

## 十、学生回答必须具有课堂功能

学生回答至少发挥一种作用：提供新观点、暴露误区、引出矛盾、成为追问对象、形成观点比较、提供概括素材或推动知识生成。为每个关键回答写明“教师使用其中的什么信息，接着怎样处理”。

例如合理但不完整的回答，可用于补充条件；与他人理由不同的回答，可用于比较依据；成熟回答可用于检验边界或形成概括，不只选择最接近标准答案的一位学生来替教师说结论。

若无论回答内容如何，教师的追问、支架、比较、板书和概括完全不变，互动很可能是形式性的。PPT顺序未变本身不是结论：教师可以保持主线而根据回答改变处理方式。

模拟授课也应设计合理的回答分支及其课堂作用。与其只写“学生回答正确”，不如写“可能出现A、B、C类回答，分别暴露不同程度的理解，教师据此补充条件、比较依据或进入概括”。分支数量按任务需要，不为展示而全部演一遍。

## 十一、没有真实学生时，怎样体现学生主体

无生试讲不能靠大量“这位同学说得很好”“大家讨论得很热烈”制造学生存在感。应展示学生需要做的认知任务及教师如何处理可能产出：

1. 清楚交代对象、任务和产出要求，使听者知道学生需要想什么。
2. 按比赛形式留出合理思考安排；具体呈现是否需要完整等待，应根据章程调整，但教案不能虚构不可能的用时。
3. 呈现有代表性的可能回答，并标明是预设。
4. 对不同或不完整回答作必要比较、澄清或追问，不只是泛泛表扬。
5. 利用回答中的关键词和关系推进板书与理论建构。
6. 说明或呈现认识如何被补充、修正或深化，再用适量迁移检验预设路径。

不要虚构过多完美答案，也不要强行编造错误。根据学情与任务合理预设不完整性、差异性和典型误区；真实学生缺席本身不扣分，教师不模仿学生声线也不代表学生主体弱。

评价必须区分设计预评、模拟呈现与实际课堂。无生试讲只能支持“设计了可实施的认知任务与回应路径”，不能声称真实学生已经改变认识或全班已经达标。预设分支很多也不自动说明教师具备实测的临场应变能力。

## 十二、学生可能回答的设计规则

从活动对象、学生起点和所给信息生成回答，而不是先写标准答案再刻意拆碎。尽量覆盖A、B、C三个层次，必要时加入D类；这是回答状态分类，不是给学生贴固定能力标签，也不要求每个小问题都出现四类。

### A类：直觉型回答

基于生活经验，可能触及现象但尚未分析原因。例如“每个人想法不一样”。

**用途**：找到已有起点与模糊词，支持从现象进入比较或解释。不能仅因语言朴素就判错误。

### B类：部分正确回答

已经触及相关学科原因，但缺少条件或联系。例如“因为他们的利益不同”。

**用途**：要求依据、补足条件，检查该原因如何影响判断，避免用一个因素解释所有情况。

### C类：较成熟回答

综合条件并接近理论表达。例如“不同主体的社会地位、需要、利益和认识角度不同，会形成不同价值判断”。

**用途**：核查材料依据与适用条件，提取可概括关系；不能把术语多当成成熟，学生还需能说明关系。此处为用户提供方向的教学示意，正式概念表述仍应核对所用教材。

### D类：典型误区

暴露推理跳跃或概念混淆。例如“既然每个人都不同，所以没有谁对谁错”。

**用途**：区分“判断差异的形成原因”与“判断是否合理的依据”，为检验解释边界提供入口。不要把描述差异直接等同于合理性，也不把学生意见不同本身当作错误。

### 回答分支的记录要求

每类记录“可能回答—依据或缺口—教师支持方向—预期变化—下一步用途”。典型例子只是可能表达，不代表现实主体一定持某种立场，也不能当作已观察到的学生发言。

教师重点使用回答间的差异，不只挑选C类；实际出现预设外回答时，先判断其依据和与任务的关系，再决定澄清、比较或概括。详细追问方法见 [教师追问设计规则 V1.0](teacher-follow-up-questions.md)，本节只规定回答与支持之间的接口。

## 十三、十四种认知活动的简明设计规则

以下每类均先确定对象和产出，再选行为载体。活动难度由实际任务决定，不由名称决定。

### 1. 提取

- **任务与适用问题**：筛选与后续判断有关的信息，适合询问“哪些信息能支持或限制这一解释”。
- **低效设计**：抄完整段材料，或只寻找教师标出的答案。
- **提升质量**：给出筛选目的，要求指出信息出处及下一步用途，形成可供比较或论证的信息集合。

### 2. 比较

- **任务与适用问题**：发现对象在同一维度上的异同及其意义，适合方案、理由、立场或条件比较。
- **低效设计**：只问“有什么不同”，学生罗列互不对应的特点。
- **提升质量**：提供明确维度，或让学生说明所发现的维度及理由；比较后解释差异怎样影响判断。

### 3. 分类

- **任务与适用问题**：根据标准组织信息，适合区分事实与观点、不同类型理由或适用条件。
- **低效设计**：仅按教师给的标签填空，不理解分类依据。
- **提升质量**：要求说明标准和边界，处理一个容易混淆的对象，允许在发现问题后修订分类。

### 4. 归因

- **任务与适用问题**：解释结果或差异的形成条件，适合“为什么同一事项出现不同判断”。
- **低效设计**：罗列原因词语，把相关现象直接说成唯一原因。
- **提升质量**：用材料说明因素如何影响结果，区分主要解释、必要条件和待验证推测，避免超出证据强度。

### 5. 判断

- **任务与适用问题**：依据事实或标准确定结论是否成立，适合检验某观点、解释或做法。
- **低效设计**：只齐答对错，或答案被暗示。
- **提升质量**：要求给出判断标准与理由，说明条件改变后是否仍成立；记录结论及其依据。

### 6. 选择

- **任务与适用问题**：在可比较的选项间作取舍，适合方案、行动或立场选择。
- **低效设计**：只投票，或一个选项显然正确、其余没有讨论价值。
- **提升质量**：使选项有可分析的差异，要求说明选择依据与放弃其他选项的理由；初判选择可简短，后续再检验。

### 7. 解释

- **任务与适用问题**：说明现象、关系或结论为什么成立，适合“该条件怎样影响判断”。
- **低效设计**：换词复述原句，或用结论解释结论。
- **提升质量**：要求连接事实、关系与结论，补出中间推理；解释应让他人理解，而不只是听见一个术语。

### 8. 质疑

- **任务与适用问题**：发现解释的证据、前提或边界问题，适合“现有理由是否足够”。
- **低效设计**：只要求“提出疑问”，学生问无关细节或故意否定。
- **提升质量**：把疑问指向具体依据或条件，说明为什么值得检验；以待解决问题为产出，不以反对数量为标准。

### 9. 辨析

- **任务与适用问题**：分清易混概念、观点中合理与不足的部分及适用条件，适合部分正确或看似矛盾的观点。
- **低效设计**：非黑即白选答案，教师立即公布正确说法。
- **提升质量**：要求说明保留什么、修正什么、为什么；用概念边界和证据处理真正分歧。

### 10. 论证

- **任务与适用问题**：以证据和推理支持或反驳主张，适合不同解释需要比较时。
- **低效设计**：堆例子或口号，只有立场没有推理。
- **提升质量**：明确主张、证据与连接理由，并处理一个相关反例或不同解释；不把发言有气势当作论证充分。

### 11. 概括

- **任务与适用问题**：提炼若干分析结果的共同点或核心关系，适合辨析后的归纳。
- **低效设计**：教师给总结让学生朗读，或逐项复述不形成共同认识。
- **提升质量**：让学生说明保留了哪些共同关系、依据是什么，形成简洁但不遗漏关键条件的表达。

### 12. 抽象

- **任务与适用问题**：暂时排除非关键情节，提取可跨案例使用的关系，适合从具体认识进入概念或原理。
- **低效设计**：把抽象等同使用大词，或由单个案例宣称证明普遍规律。
- **提升质量**：说明哪些条件保留、哪些细节不决定该关系；教师规范理论并交代边界，不虚构学生独立推出全部理论。

### 13. 评价

- **任务与适用问题**：依据明确标准分析观点或方案的合理性、效果和局限，适合现实问题、价值判断或方案评估。
- **低效设计**：只说“很好、不好、我喜欢”，或把赞同程度当依据。
- **提升质量**：说明标准及其适用性，用事实评估具体方面，形成带理由和条件的评价；不以标准数量越多越好。

### 14. 迁移

- **任务与适用问题**：在变化条件下使用已形成的认识，适合简短新情境判断、解释或决策。
- **低效设计**：只换人名、复述原答案，或另考新知识点。
- **提升质量**：改变一个有意义的条件，要求独立选择并使用相应依据；教师检查误用而不先给结论。独立运用不等于撤去所有必要事实和支架。

## 十四、认知活动与核心素养

认知活动与核心素养之间是间接关系，不能机械写成“小组讨论 → 培养公共参与”，也不能凭一次正确回答宣称某种素养已经形成。

先设计真实学习任务，再根据对象、判断依据、认知产出与学科要求，判断主要指向科学精神、政治认同、法治意识、公共参与等哪方面。判断、论证、辨析、评价现实问题可以提供相关素养发展的学习机会，但活动动词本身不决定素养归属或实际成效。

采用“具体任务 → 学生需要使用的认识或依据 → 可观察表现 → 可能支持的素养方向”的说明方式，并依据所用课标核验正式要求。例如比较证据与检验理由，可支持有依据的分析；是否涉及法治意识，还要看学生是否运用了相应规则与程序依据，不能只因讨论发生在公共议题中就贴上标签。

不要为覆盖四个核心素养强行增加活动。15分钟内聚焦所选片段能够落实的要求，并区分一次课堂表现与长期素养发展。

## 十五、认知活动失败类型

### 1. 行为替代认知型

- **典型表现**：只写观看、阅读、讨论，不说明思维任务。
- **问题原因**：外显动作无法说明学生需要理解什么。
- **修改方向**：补齐操作、对象和产出；若只是记录省略，先核对实际要求再诊断。

### 2. 热闹互动型

- **典型表现**：抢答、表演、投票频繁，产出主要为复述或口头赞同。
- **问题原因**：形式参与占用时间，却没有理由处理或认识推进。
- **修改方向**：减少切换，保留能要求判断、依据和修正的关键任务。

### 3. 材料抄答案型

- **典型表现**：全部答案可直接照抄，教师把摘录当作理论理解。
- **问题原因**：只能检验信息定位，不能充分支持解释与运用判断。
- **修改方向**：保留必要提取，把所得信息用于比较、分析条件或检验观点。

### 4. 低阶活动重复型

- **典型表现**：换材料后仍反复提取、复述，没有更深入的任务。
- **问题原因**：活动之间不增加认识，核心学习停留在事实表层。
- **修改方向**：检查后问依赖，增加基于前面产出的分析或辨析，合并无必要重复。

### 5. 学生答案工具化

- **典型表现**：只挑最成熟回答替教师说标准结论，忽略其他理由与困难。
- **问题原因**：学生成为串讲工具，回答的差异没有被转化为学习资源。
- **修改方向**：利用A、B或D类回答的依据与缺口组织比较；也允许C类回答接受条件检验。

### 6. 小组讨论形式化

- **典型表现**：宣布讨论后很快说“非常热烈”，没有明确产出或观点处理。
- **问题原因**：分组未承担需要交流的认知任务。
- **修改方向**：明确共同要解决的比较或解释问题、产出和反馈方式；若独立思考更适合，不强设小组形式。无意见冲突本身不判无效。

### 7. 活动与问题链脱节

- **典型表现**：活动有趣，却不使用前问认识，也不为后问提供依据。
- **问题原因**：学习节点与核心问题分离。
- **修改方向**：说明前问产出与本问用途、再说明本问如何支持下一问；无法建立关系时删去或替换。

### 8. 教师代替学生思考

- **典型表现**：提示直接包含全部推理，学生只补词或认可。
- **问题原因**：没有留下需要学生完成的关键认知工作。
- **修改方向**：根据实际卡点提供最小支架，保留判断与理由构建；必要知识说明不自动算代思考。

### 9. 学生回答不进入课堂

- **典型表现**：有多种回答，但教师不提取任何内容，原稿、支架和总结完全不变。
- **问题原因**：回答没有课堂功能，生成性停留于口号。
- **修改方向**：为关键产出明确比较、追问、纠偏、板书或概括用途，检查实际实施是否使用。

### 10. 认知活动没有产出

- **典型表现**：活动结束只能说“学生参加了”，无结果或变化可说明。
- **问题原因**：任务完成标准不清楚，难以判断学习是否发生。
- **修改方向**：确定适度可观察的比较、理由、概括或迁移结果，不为留痕增加大量写作。

### 11. 活动难度失衡

- **典型表现**：起点就要求陌生理论，或全程只有显然答案。
- **问题原因**：前者使学生无从进入，后者无需发展认识。
- **修改方向**：核验前置知识与信息条件，形成可进入、可分析、需辨析、能运用的整体梯度。

### 12. 活动过多导致思考时间不足

- **典型表现**：多个材料、小组任务和汇报挤入15分钟，思考与反馈被跳过。
- **问题原因**：流程看似完整，主要认知过程没有实施空间。
- **修改方向**：围绕主情境与核心问题合并为少量关键节点，核算实际用时，优先删装饰与重复。

## 十六、Agent生成与质量检查器

### 1. 生成活动的执行流程

1. **读取输入**：提取核心问题、六步节点、学生起点、材料、比赛形式与时限。已有用户确认的问题链就沿用；缺少关键条件时只追问必要项，其他假设标明。
2. **确定认知工作**：对每个节点写“学生要对什么对象进行什么操作，依据是什么”，按四层分类检查任务要求，避免只写活动名称。
3. **确定产出与支持**：写出相对起点的变化、可能回答及其缺口；再确定教师帮助什么、仍由学生完成什么。
4. **选择行为载体**：根据任务需要选独立阅读、交流、写作或其他合规形式，不先安排热闹活动再寻找理由。
5. **连接与计时**：让本产出进入下一问题，把相邻功能合理合并为3—5个主要节点，核算时间；不固定六个活动。
6. **运行下列检查器**：修正高风险项后，按标准结构交付活动节点、认知升级路径、用时合计和待核验项，不自动扩写完整教案。

### 2. 逐环节十问

对每一个学习环节记录回答及证据位置：

1. 学生表面上在做什么？
2. 学生实际上需要进行什么认知操作？
3. 认知对象是什么？
4. 学生需要产出什么？
5. 这个任务是否需要真正思考，而不只是抄答案或按提示确认？
6. 是否存在不同答案或解释空间？若结论确定，是否仍需比较理由或检验条件？
7. 教师如何根据学生产出继续推进？
8. 它与前一个问题是什么关系？
9. 它是否为后一个问题提供基础？收束节点则说明如何反馈与结束。
10. 学生完成后，认知发生了什么变化？

第2、4、7、10项中任一项无法回答，标记为“高风险形式化活动，待复核”，说明缺的是操作、产出、课堂功能还是变化证据。若材料已充分且设计本身缺少这些功能，应重新设计；若只是资料或录像不完整，标证据不足并索取必要信息，不能直接断言真实课堂无效。

这个检查标签不是新增的评分扣分项或封顶条件。最终评分依现有评价标准中的具体证据、锚点及限制执行。

### 3. 诊断已有活动并验证修改

先还原实际问题、学生任务、回答与教师处理；再运行十问，按失败类型给出“位置—行为证据—认知缺口—最小修改—待观察变化”。同一问题的重复表述合并，不因多个名称就扩大严重程度。

修订时优先恢复关键节点的认知工作与产出用途，保留已确认六步结构和核心主线。检查难度、产出、前后依赖与用时是否改善；设计和模拟材料只能支持相应预评，真实学习变化需实际证据。

## 十七、学生参与15分辅助评分建议

### 1. 适用边界与权重

本节仅提供内部辅助诊断。正式“学生参与与互动质量”仍为 [competition-rubric-100.md](../rubrics/competition-rubric-100.md) 第6项15分，沿用其整体分档、证据模式与硬性限制，不改权重，不新增扣分规则。

| 辅助维度 | 满分 |
| --- | ---: |
| 认知活动真实性 | 3 |
| 学生思维深度 | 3 |
| 互动与问题链融合 | 3 |
| 学生回答的课堂功能 | 2 |
| 认知升级与观点修正 | 2 |
| 参与密度与时间控制 | 1 |
| 迁移与独立运用 | 1 |
| **合计** | **15** |

分别标注“正式第6项评分”和“学生参与辅助诊断分”，不得相加或默认用辅助合计替代正式分。辅助合计较高，也不能补偿正式优秀锚点所要求的回答处理和认识推进缺口；辅助分与正式分不同须说明依据。

区分容易重叠的维度：真实性看任务是否确实要求学生思考；深度看推理复杂程度与依据；融合看活动位于问题链的何处、承担什么功能；回答功能看教师实际或模拟如何使用产出；升级看前后认识变化。相同证据可支持不同判断，但每项要说明不同作用，不重复设置额外奖惩。

### 2. 辅助分的可观察锚点

采用0.5分步长。满分条件须有相应证据；部分分中，关键功能缺口靠近下限、局部不足靠近上限，并注明原因。0分仅用于已确认功能不存在或无效；缺少材料标待评，不记0分、不按剩余项目折算15分。

- **认知活动真实性，3分**：3分为主要节点均有明确认知操作、对象与产出，学生确实承担关键思考，或模拟设计明确保留了该任务；1.5—2.5分为主要任务成立，部分节点仍由摘抄或提示代答；0.5—1分为行为形式清楚但仅有零星认知任务；0分为未提供有意义的认知任务。
- **学生思维深度，3分**：3分为关键节点要求基于依据进行辨析、论证或概括，不仅表态；1.5—2.5分为已有解释判断，但关键推理不充分或部分由教师替代；0.5—1分为主要提取复述，理由表达孤立；0分为无需处理相关信息与依据。
- **互动与问题链融合，3分**：3分为主要活动均使用前面认识并向后提供基础，关键认知功能有承载；1.5—2.5分为主线基本连接但部分互动并列或跳步；0.5—1分为主要按媒体或形式串联，与核心问题联系薄弱；0分为互动与认知推进无关。
- **学生回答的课堂功能，2分**：2分为能定位回答中的信息如何改变追问、支架、比较、板书或概括；1—1.5分为有针对性处理但使用范围或作用有限；0.5分为主要泛泛表扬，仅偶尔提及回答；0分为回答不被使用或全部由教师包办。
- **认知升级与观点修正，2分**：2分为能比较起点与后续认识，说明修正或深化及其依据；1—1.5分为有变化线索但理由或前后联系不充分；0.5分为只增加术语、信息，未明确解释怎样深化；0分为没有相关认知推进。
- **参与密度与时间控制，1分**：1分为少量节点各有作用，思考和反馈安排适合15分钟或规定时限；0.5分为主要节点可实施但局部仓促或切换偏多；0分为核心思考被明显挤掉。这里不按活动数或发言次数评高低，也不重复正式第9项的基本功评分。
- **迁移与独立运用，1分**：1分为学生需在有意义的新条件下自行选择并使用相应依据，教师未预先代答；0.5分为有运用任务但提示偏多或理由要求不足；0分为没有相关运用机会或只有原答案复述。这里看学生承担的运用工作，不另增正式知识生成或教学评指标的分数。

按实际课堂、模拟呈现、设计预评区分证据：预设回答只支持路径判断，不能证明实际学习效果。此辅助拆分未经实测一致性校准，不将0.5分差异解释为精确测量，也不据此推断真实比赛胜负。

## 十九、学生认知活动自检

逐项标记“通过／待修改／证据不足”，附节点编号或可核验位置。设计预期与实际表现分别说明，不只打勾。

- [ ] 是否明确学生真正的认知任务，并写出操作对象？
- [ ] 是否避免只写“阅读、讨论、回答”？
- [ ] 是否明确活动的认知产出？
- [ ] 学生是否需要解释或提供依据？
- [ ] 是否存在比较、判断、质疑、辨析等符合任务实际要求的高阶活动，而非仅有动词标签？
- [ ] 学生回答是否可能存在差异，并允许有依据的不同表达？
- [ ] 教师是否真正使用学生回答推进课堂？
- [ ] 学生是否至少经历一次观点修正或认识深化？
- [ ] 活动是否与问题链紧密连接，六步认知功能未被改写或遗漏？
- [ ] 认知难度是否整体逐步提高，必要回看是否服务于深化？
- [ ] 是否避免活动过多、过碎？
- [ ] 是否适合15分钟或规定时限，并计入真实思考、反馈和板书时间？
- [ ] 是否存在真正独立运用或迁移，而非教师先给答案？
- [ ] 如果删除学生互动，课堂的推理依据、追问、支架或知识建构是否会明显改变？
- [ ] 模拟授课中的回答是否标为预设，避免把完美脚本当作真实学习证据？
- [ ] 如涉及评分，是否区分辅助诊断与正式第6项评分，未改变15分权重？

最后做删除检验：如果删除学生所有回答，教师仍可完全照原稿完成同样的推理、支架、板书与结论生成，说明学生主体性存在明显问题。检验的是回答有没有功能，不是教师能否维持PPT顺序；有主线不等于没有生成性。

发现高风险节点时局部修订并记录待验证产出，缺证据则如实保留待核验项；不自动扩写其他方法文件或完整教案案例。
