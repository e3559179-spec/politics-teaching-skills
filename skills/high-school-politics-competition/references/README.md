# References 目录索引

教学材料的事实准确性检查见 [事实核查规则 V1.0](methods/fact-check.md)，按任务独立使用或嵌入设计、磨课、评价；不新增比赛评分标准。

本目录存放按需读取的具体依据；已建立核心认知冲突、六步问题链、学生认知活动、教师追问、板书与创新方法，以及比赛课内部评价标准，分别见 [methods 索引](methods/README.md) 和 [rubrics 索引](rubrics/README.md)。已建立从零设计、已有方案磨课与模拟评委工作流，见 [workflows 索引](workflows/README.md)；已建立《价值判断与价值选择》带注释示例，见 [examples 索引](examples/README.md)。

| 子目录 | 何时读取 |
| --- | --- |
| [methods](methods/README.md) | 任务需要经用户确认的具体教学或训练方法时 |
| [rubrics](rubrics/README.md) | 任务需要评价依据或比赛评分要求时 |
| [workflows](workflows/README.md) | 从零设计、磨课或模拟评委评价约15分钟比赛课，需要设计、修改、评分或方案比较步骤时 |
| [examples](examples/README.md) | 用户需要参照具体示例时 |

后续在相应子目录说明中登记实际文件链接、用途、适用范围和确认状态；这里只维护分类入口。
