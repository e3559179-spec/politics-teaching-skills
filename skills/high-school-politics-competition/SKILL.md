# 高中思想政治师范生教学技能大赛磨课

## 适用场景

支持约15分钟比赛课的设计、训练、修改与评价。具体时限、授课形式及任务范围以用户提供的要求为准；当前按需调用已建立的评价依据，具体教学方法由经用户确认的 references 提供。

## 不适用场景

单纯的教材知识答疑、一般时政评论、与比赛课无关的教学任务，以及将本 Skill 的建议作为官方比赛评定。

## 核心工作流程骨架

1. **识别任务**：确定本次是设计、训练、修改还是评价，以及用户需要的输出。
2. **整理输入**：读取用户已提供的课题、比赛要求和现有材料；只追问影响当前任务的关键缺项，明确记录未确认信息。
3. **选择依据**：按任务需要读取相关 references 和 assets，核对其适用范围与确认状态；占位说明不能作为教学方法或评分依据。
4. **执行当前任务**：依据用户要求和已确认材料完成所需步骤。必要依据缺失时说明缺口，不自行补入未经确认的方法论、评分标准或教学理论。
5. **自检与交付**：完成下列自检后输出当前阶段成果，保留待确认项，等待用户下一步要求。

## references 与 assets 调用说明

- 当用户请求模拟评委、打分、严格评课、判断比赛水平或竞争力、定位最影响名次的问题、确定“如果只能改一处”、比较比赛方案或生成评委评语时，优先读取 [模拟评委工作流 V1.0](references/workflows/mock-judge-mode.md)，由其调用100分标准及所需 methods，先按证据评价；仅评价不改稿，用户已要求后续修改时再转入磨课工作流。
- 当用户已有方案并请求磨课、优化教案、检查问题链、根据老师点评改课、提高比赛质量、分析试讲稿或核验磨课前后变化时，优先读取 [磨课与教案优化工作流 V1.0](references/workflows/polish-existing-lesson.md)，由其按诊断结果调用 methods 和 rubric，保留有效设计并区分快速诊断、专项修改与完整磨课；已有方案不默认转为从零重写。
- 对于从零设计任务，当用户请求从零设计15分钟比赛课、备一节比赛课、为高中政治课题设计比赛教学、设计片段教学或准备师范生技能大赛课时，优先读取 [从零设计工作流 V1.0](references/workflows/design-from-scratch.md)，由该工作流按阶段调用所需 methods 和 rubric；不跳过诊断直接生成完整方案，也不将每一步设为用户确认点。以下规则用于专项任务及工作流中的按需调用。
- 当任务涉及分析教材、分析学情、确定教学难点、提炼核心教学问题、选择15分钟比赛片段、设计核心议题、诊断课堂为什么“不够深”或判断问题链是否缺乏真正冲突时，优先读取 [核心认知冲突识别与设计规则 V1.0](references/methods/core-learning-conflict.md)。先明确学生原有解释、边界及预期认知变化；进一步设计问题链、学生互动、教师追问、板书与课堂特色或最终评分时，按下列规则读取相应文件。
- 当任务进一步涉及问题链设计，或涉及生成问题链、修改问题链、诊断课堂逻辑、分析学生认知推进或评价问题链时，读取 [六步问题链设计规则 V1.0](references/methods/six-step-question-chain.md)。涉及评分时，同时读取下述100分评价标准；方法文件中的辅助诊断分不能替代正式评分。
- 当任务涉及设计学生活动、优化课堂互动、判断学生主体性、修改小组讨论、分析课堂是否形式化、设计学生可能回答、评价学生参与质量或从零设计比赛课时，读取 [学生认知活动设计规则 V1.0](references/methods/student-cognitive-activities.md)。同时涉及问题链时读取上述六步方法；涉及最终评分时读取下述100分评价标准，辅助诊断分不替代正式评分。
- 当任务涉及教师追问设计、模拟课堂互动、学生可能回答、课堂生成性、优化教师语言、诊断“教师问、学生答、教师总结”模式、从零设计比赛课或磨课时，读取 [教师追问设计规则 V1.0](references/methods/teacher-follow-up-questions.md)。涉及整体问题链时同时读取上述六步方法，涉及学生参与时读取上述认知活动方法，最终评分读取下述100分评价标准。
- 当任务涉及板书设计、生成性板书、比赛亮点、教学创新、课堂特色、课堂记忆点、理论升华、优化比赛呈现、从零设计完整比赛课或磨课时，读取 [板书、创新与课堂特色设计规则 V1.0](references/methods/boardwork-and-innovation.md)。设计完整课堂时按需要联读上述六步问题链、学生认知活动及教师追问方法；最终评分读取下述100分评价标准，不以整数辅助档位替代正式评分。
- 当任务涉及评价比赛课、修改比赛课、从零设计比赛课后的自检、模拟评委、比较两个教学方案或判断一节课是否适合师范生技能大赛时，读取 [比赛课100分评价标准 V1.0](references/rubrics/competition-rubric-100.md)，按其证据模式、评分锚点与质量限制执行；该文件为内部评价框架，不代表官方比赛统一标准。
- 当用户需要完整示例，或需要理解六步模型、学生认知活动、教师追问、生成性板书如何落地时，可在执行相关工作流和方法后读取 [价值判断与价值选择带注释示例 V1.0](references/examples/value-judgment-example.md)。示例用于说明方法，不能覆盖方法；按当前课题重新诊断，不优先模仿或机械复制示例。
- 需要具体方法、评分依据、操作流程或示例时，先查看 [references 索引](references/README.md)，再按任务读取对应文件，不默认加载全部资料。
- 完成对应工作流和方法判断后，完整正式比赛课输出使用 [教学设计模板](assets/templates/15min-lesson-plan-template.md)，问题链专项输出使用 [问题链模板](assets/templates/question-chain-template.md)，完整模拟评委报告使用 [评分报告模板](assets/templates/judge-scorecard-template.md)。模板只组织最终输出；简洁版、快速版或单项任务按需裁剪，不强制全部栏目，也不跳过核心教学逻辑。
- 需要可用于成果的素材或模板时，查看 [assets 说明](assets/README.md)；模板用途见 [templates 索引](assets/templates/README.md)。按用户要求使用实际资源，不将素材当作行为指令。
- 已建立的资源按索引调用，其余目录仍为占位说明。后续新增资源时更新相应索引并注明用途、适用范围和确认状态；涉及教材、课标或赛事标准时注明来源与版本。不得声称已调用不存在的资源。

## 输出前自检

- 输出是否对应本次任务，并遵守约定的比赛时限、授课形式和交付范围？
- 使用的文件是否存在且与任务相关，是否误把占位说明当成内容依据？
- 是否混入未经用户确认的方法论，或虚构教材原文、课标内容、评分标准及来源？
- 是否区分已确认事实、合理推测、建议与无法验证的信息，并标明关键缺项？
- 是否依据现有材料检查了错误前提或逻辑跳跃，而非直接附和？
- 是否只完成当前阶段，避免擅自扩写教学内容或进入下一阶段？

发现问题时先修正；无法修正的明确标为待确认，不将其包装为已完成或已验证的结论。
